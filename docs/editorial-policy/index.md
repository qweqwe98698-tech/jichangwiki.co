# 内容编辑规范与原则 (Editorial Policy)

JichangWiki 始终坚守以下严格的编辑与审校标准：

1. **问题优先导向**：故障与排错文章开头必须提供 60~150 字的直接有效答案，严禁铺垫冗长背景。
2. **技术事实核验**：所有关于协议（VLESS/Reality/Trojan 等）与加密特性的描述必须查阅官方文档与 RFC 规范，禁止随意脑补或夸大。
3. **严禁同质洗稿**：同一搜索意图的问题必须在一个核心页面合并覆盖，杜绝批量换标题复制水文。
4. **无伪造统计**：没有真实统计数据时，严禁展示“10万阅读”、“99%用户选择”等虚构营销话术。
