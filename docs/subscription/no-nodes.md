# 导入后没有节点 / 节点列表为空排查

<AnswerBox question="导入订阅成功了，但为什么一个节点都看不到？">
主要有三个可能原因：① 机场账户因欠费或流量耗尽，后端下发了空的节点列表；② 客户端开启了「节点过滤正则」，把所有节点都过滤掉了；③ 订阅中包含的所有协议类型（如 Reality）你的旧版本客户端内核无法识别。
</AnswerBox>

---

## 🔍 排查与修复

1. **检查客户端节点过滤设置**：检查是否有误设的关键字过滤正则（如 `香港`、`专线` 等），将其清空重试。
2. **升级客户端内核**：若机场节点全部升级为较新的 VLESS-Reality 或 Hysteria2，而你的客户端使用的是两年前的老旧内核，客户端会因为无法识别协议字段而自动忽略该节点。
3. **核查机场套餐余额**：登录机场官网，确认套餐剩余流量大于 0。
