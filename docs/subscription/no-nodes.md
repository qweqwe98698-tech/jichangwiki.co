# 导入后没有节点 / 节点列表为空排查

<AnswerBox question="客户端显示「订阅下载成功」，但为什么一个可用节点都看不到？">
当下载成功却看不见节点时，主要排查 3 个方向：① <strong>账户已欠费或流量耗尽</strong>（后台下发空列表或只下发过期提醒）；② <strong>客户端误设了节点过滤正则</strong>把线路全过滤掉了；③ <strong>旧版本客户端内核无法识别机场新增的 VLESS-Reality / Hysteria2 协议</strong>而被默默丢弃。
</AnswerBox>

---

## 一、快速自检清单（按命中概率从高到低排查）

### 1. 核对机场套餐状态与最近一次续费同步
很多面板在套餐刚失效时**不会报错 404**，而是正常返回一份合法的配置文件，但里面故意删光真实线路，只塞进 1~2 条名叫 `[官网: xxx / 套餐已过期]` 的占位假节点，所以软件会诚实地显示「更新成功（1~2 个项目）」。
- 怎么确认：按 [订阅过期与流量耗尽判断](/subscription/expired) 核实剩余流量与有效期；若刚充值续费，务必重启/手动再次「更新订阅」。

### 2. 检查客户端是否开启了过滤关键字（极易被忽视的隐藏项）
如果你曾经修改过客户端的：
- **v2rayN**：订阅分组设置 ➔ `筛选 (Filter)` 文本框是否错填了正则（如错写 `^$` 或不匹配的字符）？
- **Clash Verge / 订阅转换链接**：是否在订阅后缀加过 `&exclude=` 或 `&include=` 把节点全筛没了？
- **Shadowrocket**：首页是否打开了按区域/名称搜索过滤框却忘了清空？

### 3. 老旧客户端内核静默丢弃了新协议节点
随着 2025~2026 主流机场广泛部署 **VLESS-Reality**、**Hysteria2** 与 **AnyTLS** 等新式协议，大量两年前停止维护的老版本软件（如旧版 Clash for Windows、过旧版 v2rayNG / 小火箭）遇到不认识的 `type` 字段会直接忽略整条节点。
- **验证与解决**：用新版本的 **Clash Verge Rev（Mihomo 内核）** 或升级版 v2rayN / Shadowrocket 重新导入。Clash Verge 导入操作看 [Clash Verge 订阅导入](/clients/clash-verge/import-subscription)。

### 4. 未切换选中刚刚导入的那个订阅卡片（Profile）
在 Clash Verge Rev 等多配置管理软件中，仅仅点「导入并保存」有时还需要**手动单击一下新增出来的订阅卡片使其变成高亮激活状态**。若客户端界面依然停留在内置的空白 Default 默认档案上，代理页当然什么都看不见。

## 二、进阶验证：看懂返回文件本身是不是空的

如果你手边有电脑，把你的 Clash 格式订阅粘贴到浏览器打开下载出一个 `.yaml` 文本，用记事本打开找 `proxies:` 这一行：
- 如果 `proxies:` 下面清一色列出几十个 `name / server / port`，证明机场给的数据完全充足，100% 是本地客户端版本或过滤规则吃掉了它们。
- 如果文件里 `proxies: []` 或者总共只有三五行字写着提示信息，立刻登录机场官网工单联系客服或检查套餐过期状态。

## 常见问题解答（FAQ）

### 提示订阅更新成功，但界面上只有两条「剩余流量」「到期时间」没有真节点是怎么回事？

绝大多数是你的机场套餐已经过期或本月/总量配额耗尽，服务端按协议只下发了两条说明状态的提示型假节点；也有可能是你刚刚续费，服务端缓存未刷新或还没重新点击客户端的「更新订阅」。

### 我的账户明明还有很多流量且未到期，为什么导入还是 0 个节点？

重点排查客户端「节点名称正则过滤（Filter / Include / Exclude）」是否无意中填入了苛刻条件，或者机场已全面升级为 `VLESS-Reality` / `Hysteria2` 节点，而你的老旧客户端无法识别新协议导致自动将其屏蔽。

### 导入后代理列表能看见节点，但全局测速全红或超时怎么算？

列表看得到节点就不是「无节点」问题，而是节点连通性故障。请确认已打开正确代理模式、校准系统时间并查看 [全节点超时 Timeout 排查手册](/troubleshooting/all-nodes-timeout)。
