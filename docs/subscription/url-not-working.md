# 订阅链接打不开或无响应排查指南

<AnswerBox question="订阅链接在浏览器打不开、客户端拉取一直超时怎么办？">
按顺序做 3 步快速验证：① <strong>核对复制是否完整</strong>（确保以 <code>https://</code> 开头、没有多余空格或微信转义符）；② <strong>切换手机流量或借助可用备用代理在浏览器直接打开该 URL 测试</strong>（区分本地网络拦截与服务商宕机）；③ 若页面返回 <code>401/403/404</code>，则需登录官网重置订阅 Token。
</AnswerBox>

## 一、在浏览器中测试订阅链接的判断标准

当客户端始终转圈提示 `fetch failed` 或 `timeout` 时，直接把订阅 URL 贴到 Chrome / Edge / Safari 地址栏打开是最直观的定位方法：

- **下载了 `.yaml` / `.txt` 或满屏乱码字母**：说明订阅链接和机场后端本身**完全正常**！问题出在你本地客户端格式选错或旧代理死锁，请转向 [更新订阅失败排查](/subscription/update-failed) 或 [导入订阅报错处理](/subscription/import-failed)。
- **浏览器提示「无法访问此网站 / 连接超时」**：说明订阅 API 域名遭到当前宽带阻断、本地 hosts 冲突或服务商节点全线 offline。
- **网页明确显示 Nginx/Cloudflare 的 `403 / 404 / 502` 字样**：能连到服务器但被后端接口拒绝，需对照下方状态码处理。

## 二、常见 HTTP 状态码与系统错误对照表

| 网页 / 日志具体现象 | 核心原因判定 | 针对性解决操作 |
| :--- | :--- | :--- |
| **`ERR_CONNECTION_TIMED_OUT`** | 订阅域名在本地 ISP 被 DNS 投毒或端口屏蔽 | 用手机 4G/5G 热点试打开；或先连备用节点再刷新；去官网找备用订阅域名 |
| **`404 Not Found`** | 订阅路径变更或你曾在后台点过「重置订阅」，旧 Token 作废 | 登录机场官网账户重新复制最新的订阅地址替换 |
| **`401 / 403 Forbidden`** | 鉴权 Token 被吊销、账户过期封禁，或防火墙屏蔽了请求 User-Agent | 查看套餐是否有效；确认客户端未伪装异常 UA，必要时重置订阅链接 |
| **`502 / 504 Bad Gateway`** | 机场面板或后端订阅生成服务临时过载或正在维护 | 等待 10~30 分钟后再试；持续数小时未恢复需关注官方公告渠道 |
| **`SSL / TLS Certificate Error`** | 订阅域名证书过期，或本地电脑系统时间严重不准 | 在操作系统校准「自动设置网络时间」，确认无学校/企业网络中间人劫持 |

## 三、3 个极易忽略的 URL 格式细节

1. **聊天软件自动转义破坏链接**：通过某些 IM 工具传订阅链接，常把地址中的 `&flag=clash` 转义成 `&amp;flag=clash` 或截断后半段。
2. **手动框选遗漏开头字母**：少复制开头的 `h`（变成 `ttps://...`）或末尾少 1 位 Token 字符，都会直接报参数错误。
3. **混入全角符号或换行**：粘贴时确认光标前后没有回车空行与中文全角空格。

## 常见问题解答（FAQ）

### 把订阅链接直接粘贴到浏览器打开应该看到什么？

正常有效的订阅地址在浏览器打开后，要么会触发下载一个 `.yaml` 文件（Clash 格式），要么直接在网页显示一长串乱码般的字母（Base64 格式节点内容）；只有看到 HTML 404 错误页、无法访问提示或空白页才说明链接请求异常。

### 浏览器显示 ERR_CONNECTION_TIMED_OUT 但机场后台能登录是什么情况？

说明机场专门用来下发订阅的 API 域名当前在你所在网络环境下被 DNS 污染或防火墙拦截了。可以切换手机 4G/5G 热点拉取，或在官网查找官方公告提供的最新「备用订阅域名」。

### 机场官网也打不开了，怎么拿到最新的备用订阅链接？

优先查看自己保存过的机场官方防失联发布页、GitHub 发布通知或官方公告频道；若客户端里仍有任意一条老节点能正常连通，也可以先开全局代理再访问旧官网跳转到最新地址。
