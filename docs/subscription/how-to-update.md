# 如何更新订阅与设置自动策略

<AnswerBox question="为什么要定期更新订阅？建议多久更新一次？">
因为机场服务商会定期维护服务器、更换被阻断的入口 IP 或上线新的地区节点。建议在客户端开启「打开软件时自动更新」或设置每 12~24 小时自动更新一次。
</AnswerBox>

---

## ⚙️ 最佳自动更新设置推荐

1. **Clash Verge Rev**：在订阅 Profile 上右键选择「编辑信息」，将「更新间隔」设置为 `1440` 分钟。
2. **v2rayN**：在「订阅分组设置」中勾选「自动更新」，在基础设置中设定每日清晨定时自动同步。
3. **Shadowrocket**：在「设置」→「订阅」中开启「打开时更新」。
