# 如何正确导入订阅到各大客户端？

<AnswerBox question="新买的机场订阅链接，各平台软件通用的正确导入姿势是什么？">
无论使用哪款代理客户端，通用安全三步法都是：<strong>① 在机场后台对应设备栏选择正确的客户端格式并「复制订阅地址」；② 打开本地客户端进入订阅/配置页粘贴 URL 并下载配置文件；③ 在节点列表选中可用线路后开启「系统代理」或 VPN 开关</strong>。<br>
（不建议用微信/QQ 中转转发订阅文本，也不推荐盲目依赖可能被系统拦截的一键唤起按钮。）
</AnswerBox>

## 二、导入前务必核对的 4 项基础检查（避开 90% 报错）

1. **格式必须匹配**：Clash 系软件只吃 `YAML`；v2rayN 与小火箭大多吃通用 `Base64` 或官方自适应链接。具体差异见 [常见订阅格式对比](/subscription/formats)。
2. **链接头尾不能有多余空格或中文**：手动框选复制很容易漏掉开头的 `h` 或在末尾多带空格、换行符，尽量直接使用机场提供的「一键复制」按钮。
3. **清理之前冲突的旧代理**：若电脑以前开过其他加速器或浏览器梯子插件，先彻底退出，避免客户端拉取新订阅时请求被死去的旧代理截留。
4. **切忌直接点击高风险网页版一键导入失败后反复点**：若 `clash://` Scheme 唤起无响应，请立刻切换为**复制链接 ➔ 手动新建 Remote Profile 导入**。

## 三、导入后下一步如何确认已经生效？

成功保存远程订阅后，还必须完成以下收尾动作才算真正跑通：

- **第一步：核对节点列表是否出现（且余量正确）**。若导入后发现节点数为空，请查阅 [导入后没有节点排查](/subscription/no-nodes)。
- **第二步：切换策略与单节点测速**。选中一个常用地区节点并做一次真实延迟测试；若全部显示 Timeout，参照 [全节点超时 Timeout 急救指南](/troubleshooting/all-nodes-timeout)。
- **第三步：开启「系统代理」或「VPN」总开关**。仅把节点导入软件列表并不会接管浏览器流量，必须打开总开关，才能通过规则分流访问目标站点。

## 常见问题解答（FAQ）

### 点击机场官网「一键导入 Clash」没反应或弹出打不开网页怎么办？

一键导入依赖浏览器唤起系统 URL Scheme（如 `clash://install-config`）。若系统未绑定默认协议或电脑装了多个版本 Clash，就会失败；最稳妥的方式是改为「复制订阅地址」，然后到软件内部手动粘贴 URL 点击导入。

### 在电脑端登录的机场，手机端也需要重新买套餐吗？

不需要。正规机场按账户限制或开放多端同时在线，只需用手机浏览器登录同一个机场账号，复制（或扫码）适合手机客户端格式的订阅链接导入即可共用同一份套餐流量。

### 导入时一直转圈或提示连接被重置怎么处理？

先检查是否同时开着另一款代理软件或浏览器插件；若属于本地网络无法访问订阅主域名，可临时切换手机热点拉取一次，或查看 [更新订阅失败通用排查](/subscription/update-failed)。
