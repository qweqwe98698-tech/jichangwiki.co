# 如何正确导入订阅到各大客户端

<AnswerBox question="不同客户端导入订阅的核心步骤是什么？">
核心动作一致：① 复制机场提供的对应格式链接；② 在客户端找到「订阅管理」或「配置」入口；③ 粘贴链接并点击「保存/下载/更新」。
</AnswerBox>

---

## 💻 桌面端导入步骤

- **Clash Verge Rev**：左侧「订阅 (Profiles)」→ 粘贴 URL → 点击「导入」→ 右键卡片选择「使用」。
- **v2rayN**：顶部菜单「订阅分组」→「订阅分组设置」→「添加」→ 粘贴 URL 并确定 → 点击「更新所有订阅(不通过代理)」。

---

## 📱 移动端导入步骤

- **iOS (Shadowrocket)**：右上角 `+` 号 → 类型选择 `Subscribe` → 粘贴 URL 并点击「完成」；或直接在首页下拉刷新。
- **Android (v2rayNG)**：左侧菜单「订阅分组设置」→ 右上角 `+` 号 → 粘贴 URL 保存 → 菜单点击「更新订阅」。
