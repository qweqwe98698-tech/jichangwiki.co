# 订阅过期与流量耗尽判断指南

<AnswerBox question="突然上不了网，怎么快速区分「套餐到期/没流量了」和「机场节点坏了」？">
按顺序查看 3 个位置即可一秒确认：① <strong>客户端订阅卡片进度条</strong>是否显示流量 100% 耗尽或已超到期日期；② <strong>手动点击一次更新订阅</strong>后节点名单是否变为只剩 1~2 条 <code>[已过期请续费]</code> / <code>[流量已用尽]</code> 占位提醒；③ <strong>直接登录机场用户后台首页</strong>确认剩余有效天数与剩余 GB 数。
</AnswerBox>

## 一、如何看懂客户端里的 3 种提醒信号

### 1. 订阅卡片元数据（最直观）
在 **Clash Verge Rev** 的 `订阅 (Profiles)` 页面，每个远程配置卡片下方都会展示类似 `48.2 GB / 100 GB · 到期 2026-12-31` 的进度条。如果它来自响应头中的 `subscription-userinfo`，注意区分两种耗尽：
- **已用 / 总量达到 100%**：即使离到期时间还有半个月，一旦月配额跑空，所有节点也会在几分钟内同步踢线。
- **日期已过期**：就算进度条上显示还有 80GB 没用完，当月到期不续费一样无法继续连通。

### 2. 「假节点」文字状态条
许多服务商会在节点池最顶端或过期清单里插入几条纯展示用的虚拟节点（不可连接，测速永远显示 `Timeout`），例如：
- `剩余流量：85.4 GB`
- `距离重置还有：12 天`
- `⚠️ 账户套餐已到期或流量耗尽，请登录官网处理`

### 3. 节点全 Timeout 但昨天还在大流量下载
如果你前一天刚刚挂着下载了大型文件、看 4K 视频或让后台客户端疯狂跑流量更新，第二天突然全员断连，首先就要怀疑流量被提前刷空。

## 二、常见计费耗尽场景与恢复步骤

| 异常表现 | 常见原因 | 正确恢复动作 |
| :--- | :--- | :--- |
| **月流未到期但提前跑空** | 高码率流媒体、网盘同步、或订阅泄露给他人跑流 | 若非自己高强度使用，**立刻在后台点击重置订阅链接**并购买流量重置包 |
| **续费买好新套餐但节点全红** | 客户端仍停留在过期时的缓存配置，未向后端重新验证 | 回到客户端点击手动「更新订阅」；若仍不通，按 [Clash Verge 更新订阅教程](/clients/clash-verge/update-subscription) 检查直连刷新 |
| **按量包看似还有余额却连不上** | 部分机场“按量不限时”套餐也有最长有效期限制或最低保持条件，或当前老订阅节点发生例行维护 | 登录官网看公告，更新订阅获取最新在线服务器列表 |

## 常见问题解答（FAQ）

### 续费买完新套餐或充完流量后，为什么节点依然连不上？

机场后台放行需要客户端重新拉取最新下发权限，甚至部分服务商在账户过期后已重置旧的节点密码或端口。续费完成后务必去客户端手动点击一次「更新订阅」，让新配置生效。

### 月付套餐「每月 1 日重置」还是「按购买日算 30 天重置」？

不同机场面板计费策略不同，有些是每月固定 1 号零点重置当月流量，有些是按用户订单激活日每隔 30 天整滚动重置。请以自己机场后台仪表盘展示的「下次流量重置时间」为准。

### 不常用梯子总觉得月付过期很浪费怎么办？

低频或仅作为应急备份的用户，更适合挑选明确标明不限时间、用完为止的按量计费产品或超轻量年付方案，可以查看站内的 [按量付费推荐专题](/recommend/pay-as-you-go) 或 [月付推荐筛选页](/navigation/monthly-pay)。
