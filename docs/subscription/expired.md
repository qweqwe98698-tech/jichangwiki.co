# 订阅过期与流量耗尽判断指南

<AnswerBox question="如何快速判断自己的代理订阅是否已经过期或用光了流量？">
① 在客户端配置卡片上方查看自动拉取的「已用流量 / 总流量」与「到期日期」；② 在浏览器直接访问订阅 URL，查看返回的 HTTP Header 中的 expire 时间戳；③ 直接登录服务商用户后台核对套餐状态。
</AnswerBox>

---

## 🛑 过期或流量耗尽的典型表现

- 点击节点测速全部显示 `Timeout` 或 `0ms`。
- 更新订阅后，节点列表中只剩下一条名为 `[已过期请续费]` 或 `[流量已用尽]` 的提示条目。
- 登录机场后台，用户状态显示为 `Inactive` 或 `Expired`。此时只需在后台完成续费或充值，再在客户端重新点击「更新订阅」即可立刻满血复活。
