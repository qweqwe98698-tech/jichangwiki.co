# 更新订阅失败通用排查指南

<AnswerBox question="更新订阅失败最常见的原因是什么？">
主要有三点：① 本地开启的代理死锁（由于旧节点不可用，通过代理更新导致请求发不出去）；② 订阅域名被 GFW 拦截；③ 机场账户欠费到期或流量耗尽。
</AnswerBox>

---

## ⚡ 快速修复三板斧

1. **第一步：关闭代理尝试直连更新**
   - 在 v2rayN 中使用「更新所有订阅(不通过代理)」；在 Clash Verge 中关闭系统代理后点击刷新。
2. **第二步：在手机流量下测试更新**
   - 如果电脑 Wi-Fi 更新失败，使用手机 4G/5G 热点更新一次，排查本地路由器 DNS 劫持。
3. **第三步：登录服务商后台核对**
   - 确认套餐是否处于有效活跃状态，并在后台点击「重置订阅链接」重新导入。
