# 什么是订阅与节点聚合？

<AnswerBox question="什么是代理订阅？">
订阅（Subscription）是**将服务商维护的所有可用节点参数聚合生成的一个固定 Web 地址**。客户端只需定期向该地址发起请求，就能一键获取所有最新服务器的 IP、端口、协议与分流策略。
</AnswerBox>

---

## 🔄 订阅机制的演进历程

1. **单节点手动配置时代（2012~2015）**：用户需要逐一输入 IP 与密码，一旦节点被封锁或机房迁移，维护极其痛苦。
2. **Base64 批量导入时代（2015~2018）**：通过包含几十条 URI 的 Base64 文本一次性导入，但仍需手动重复粘贴。
3. **现代动态 URL 订阅时代（2018 至今）**：服务端下发专属 URL，客户端自动在后台拉取与增量更新，完全实现自动化无感运维。
