# 订阅转换的原理与安全风险

<AnswerBox question="什么是订阅转换？使用公共订阅转换平台有什么安全风险？">
订阅转换是将一种格式的订阅（如 Base64）转换为另一种客户端所需格式（如 Clash YAML）的工具。**风险在于：当你把订阅 URL 提交给第三方公共转换网站时，网站运营者可以完全截获你的 Token 并偷用你的节点流量甚至窃取敏感信息**。
</AnswerBox>

---

## ⚠️ 隐私泄露威胁

1. **节点流量被盗用**：第三方转换后台可以记录你的订阅 Token，定时拉取你的节点用于公共爬虫或私自贩卖。
2. **中间人劫持插入恶意规则**：黑客搭建的恶意转换器可以在返回的规则中将你的所有流量引导至监听服务器。

---

## 🛡️ 安全使用建议

- **优先使用机场官方下发的专用格式**：绝大多数正规机场已原生支持 Clash、Shadowrocket、sing-box 格式，无需任何二次转换。
- **若必须转换，使用本地 Subconverter**：在本地电脑运行开源的 Subconverter 程序，通过 `127.0.0.1:25500` 在本机进行安全转换，数据不离开本地。
