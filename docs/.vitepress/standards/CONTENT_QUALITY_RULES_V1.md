# 通用网站内容深度自动判定与薄内容防护升级规则 V1.0

## 0. 最高优先级原则

本规则用于：
- 旧网站内容升级
- 新网站内容生产
- SEO 内容审核
- GEO / AI Search 内容优化
- Thin Content 排查
- 关键词内耗治理
- 批量文章质量门禁
- AI 自动写作质量控制

执行目标不是：
> 把所有页面强行写长。

而是：
> 根据搜索意图、问题复杂度、已有竞争页面、信息增量和用户实际需求，自动决定每个页面应达到什么内容深度。

全站遵循：
- **简单问题短而完整。**
- **复杂问题长而深入。**
- **相同意图合并。**
- **不同意图拆分。**
- **没有新增价值的页面不发布。**

## 1. 页面类型体系 (TYPE-A ~ TYPE-I)

| 页面类型 | 意图与特征 | 默认深度 | 必备核心组件与模块 |
| :--- | :--- | :---: | :--- |
| **TYPE-A｜简短定义页** | 快速理解概念 (例: DNS 是什么) | **D1** | 60~180字直接答案、核心作用、实际例子、相关词条内链 |
| **TYPE-B｜百科知识页** | 深入理解技术 (例: VLESS 是什么) | **D2** | 定义、为什么存在、工作原理(Mermaid)、特点、场景、FAQ、知识图谱 |
| **TYPE-C｜教程页** | 完成实际操作 (例: 怎么导入订阅) | **D3** | 最终目标、准备工作、分步操作、参数解剖、验证方法、报错排查 |
| **TYPE-D｜故障排查页** | 定位并解决报错 (例: 节点超时) | **D4** | 症状、30秒速解、原因树(A/B/C)、分步方案、验证测试、FAQ |
| **TYPE-E｜对比页** | 判断与决策 (例: IEPL vs IPLC) | **D5** | 快速结论、全景对比表、核心差异、优缺点、适用人群建议、FAQ |
| **TYPE-F｜选择指南** | 建立选型标准 (例: 怎么选机场) | **D5** | 选型判断树、避坑指标、不同预算推荐、场景矩阵、风险提示 |
| **TYPE-G｜评测页** | 事实证据与优缺点 (例: 品牌评测) | **D5** | 实测证据看板、基础设施架构、优缺点客观分析、适用人群、优惠卡片 |
| **TYPE-H｜排行榜/推荐页**| 商业与选择承接 (例: 专线推荐) | **D5** | 筛选控制器、排行榜表格、推荐卡片、入选理由、场景导航 |
| **TYPE-I｜Pillar 核心专题**| Topic Cluster 中心枢纽 | **D6** | 主题定义、用户入口、完整知识结构、子专题导航、全景内链网格 |

## 2. 六级内容深度等级规范 (D1 ~ D6)

- **D1 (快速答案 300~700字)**：简单定义，一句话直给 + 例子 + 相关内链。
- **D2 (标准百科 700~1500字)**：定义 + 产生背景 + 工作原理 + 特点 + 场景 + FAQ + 相关知识。
- **D3 (完整教程 1000~2500字)**：目标 + 准备 + 分步步骤 + 代码/参数 + 验证 + 下一步。
- **D4 (深度故障 1200~3000字)**：症状 ➔ 快速答案 ➔ 原因树 ➔ 原因 A/B/C 方案 ➔ 验证 ➔ FAQ。
- **D5 (深度对比/推荐 1500~3500字)**：结论 ➔ 对比表 ➔ 核心差异 ➔ 优缺点 ➔ 适用人群 ➔ 风险建议。
- **D6 (Pillar 核心专题 2500~5000+字)**：主题定义 ➔ 导航入口 ➔ 完整知识树 ➔ 子主题 ➔ 内链网络。

---

## 3. 信息增量 (Information Gain) 审核门禁

页面发布前必须至少命中以下一项增量价值：
1. 更清晰的解释与逻辑图解（Mermaid 时序/拓扑）
2. 完整的实操配置代码与参数逐行解析
3. 真实测速证据与测试数据（Speedtest 数据、时区与版本）
4. 精准的报错原因决策树与一键解决方案
5. 结构化对比矩阵与不同人群选型建议
6. 结构化直达商业承接（优惠券与专属链接）

---

## 4. 质量评分与门禁机制 (CONTENT_QUALITY_SCORE)

- **85 ~ 100 分 (PUBLISH)**：直接发布。
- **75 ~ 84 分 (PUBLISH_WITH_IMPROVEMENT)**：允许发布并记录优化。
- **60 ~ 74 分 (REWORK)**：补强后发布。
- **40 ~ 59 分 (MERGE_OR_REWRITE)**：合并或重写。
- **< 40 分 (DO_NOT_INDEX)**：禁止收录。
