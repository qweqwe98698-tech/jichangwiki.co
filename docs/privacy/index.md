# 隐私政策 (Privacy Policy)

JichangWiki 极其重视用户的个人隐私与数据安全：

1. **纯静态生成**：本站为纯静态托管网站，不设任何要求用户注册的用户系统，不收集用户的手机号、邮箱或敏感凭据。
2. **本地客户端搜索**：站内搜索功能完全基于浏览器本地 WebAssembly / Pagefind 离线执行，你的搜索关键词绝不上传至任何服务器。
3. **无恶意追踪**：本站不接入侵犯隐私的第三方跨站追踪广告网络。
