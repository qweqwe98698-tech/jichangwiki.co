## 🛡️ 二、访问官网与购买前的 3 项安全核验（防钓鱼避坑）

1. **警惕搜索引擎“广告位”仿冒站**：切勿直接点击高仿拼写错误的域名（如多一个字母或后缀异常的跳转站）。登录前核对浏览器 HTTPS 锁标与常用账户信息。
2. **订阅域名与官网域名通常分离**：如果出现官网面板能打开但订阅更新失败，或订阅可用但官网打不开，属于正常风控隔离。可参考 [订阅链接打不开排查](/subscription/url-not-working) 处理。
3. **坚持先月付或小额测试**：无论页面宣传多优惠，首次接入新服务商均建议优先单月试用（或按量流量包），验证本地三网晚高峰可用后再考虑长期周期。
