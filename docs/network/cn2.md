# 中国电信 CN2 网络深度百科

<AnswerBox question="什么是中国电信 CN2 网络？它与日常家宽走的 163 骨干网有什么本质差距？">
<strong>CN2（ChinaNet Next Carrying Network，中国电信下一代承载网，自治域号 <code>AS4809</code>）</strong>是中国电信建设的<strong>高等级精品商用骨干网</strong>，定位类似于高速公路上的「VIP 收费专用通道」；相比承载绝大多数民用家宽的普通 <strong>163 骨干网（<code>AS4134</code>）</strong>，CN2 在轻载率、单跳传输延迟及国际晚高峰防丢包方面具有代差级优势。
</AnswerBox>

## 一、两条骨干网路由对比（一眼看懂 Traceroute）

做网络排错或测量直连 VPS 路由追踪（Traceroute / BestTrace）时，只需要记住两组最具辨识度的骨干路由前缀：

| 对比维度 | 普通 163 骨干网 (AS4134) | CN2 精品承载网 (AS4809) |
| :--- | :--- | :--- |
| **标志性路由器节点 IP 前缀** | `202.97.*.*` | `59.43.*.*` |
| **主要服务对象** | 普通家用宽带、平价商业宽带及普通公网出访 | 政企跨国专线、银行金融互联与高端 CN2 GIA VPS |
| **国际出口负载情况** | **极大概率拥挤（尤其晚 20:00~23:00 常见较高丢包）** | 全网严格控制带宽冗余，高负载期依旧保持轻载运行 |
| **QOS 优先级与延迟稳定性** | 民用默认优先级，极端高峰易大幅抖动 | 企业商用最高 QOS 优先级保障，往返时延稳如直线 |

## 二、CN2 体系内的两种核心产品级差（GT vs GIA）

很多人买直连机器或者看服务商宣传只写了“CN2 线路”，其实里面藏着 **CN2 GT** 与 **CN2 GIA** 截然不同的两档价格与体验：

1. **CN2 GT（Global Transit，半程 CN2）**：国内省级到国际出口这一段依然走在拥挤的 `202.97.*` 普通 163 路上，到了出海边缘才汇进几跳 `59.43.*`，或者去程普通、回程半优化。**国内跨省及出口阻塞依然躲不掉**。
2. **CN2 GIA（Global Internet Access，全程高级双向 CN2）**：从本地市/省级网关开始便直接步入 `59.43.*` 专网直奔海外落地，回程同样全程 `59.43.*` 归来，绕开所有拥堵的 163 节点（深入对照看：[CN2 GIA 与 GT 完整比较](/network/cn2-gia)）。

## 三、CN2 公网直连 vs 现代机场 BGP 中转 / IEPL 专线

早年间大量小规模自建玩家高度迷信 CN2 GIA VPS，但到了今天主流多用户服务生态中：
- **对电信单网优势明显，对联通/移动不够统一**：纯粹电信 CN2 GIA 对电信用户友好，但移动或联通用户去程、回程未必每家都做齐三网优化；
- **仍处于公开民网过境环境**：遇到协议特征探测或公网极端抖动周期，依然比不上独立物理内网点对点穿越的 **[IEPL / IPLC 专线](/network/iepl)**；
- 因此现代正规机场多采取 **境内三网 BGP 多线汇聚中转（适配移动/电信/联通全网入口）+ 物理 IEPL 专线传输** 的架构。如果你想梳理各类网络形态取舍，推荐直接对照：[公网直连、中转与专线选择模型](/guides/how-to-choose-network)。

## 常见问题解答（FAQ）

### 同样是中国电信出境，为什么普通 163 骨干网晚高峰会严重卡顿，而 CN2 却表现稳定？

163 骨干网（`AS4134`）承载了中国电信绝大部分普通宽带的国际访问包，在用网高峰出口带宽高度饱和；而 CN2（`AS4809`）依靠昂贵专有传输资源和准入门槛控流，使拥塞率和包丢失维持在很低水位。

### 路由追踪看到 59.43.* 开头的节点就代表是顶级的 CN2 GIA 吗？

未必，需要分别看「去程」与「回程」每一跳里是否仍混夹着多跳 `202.97.*` 普通 163 路由器。只有进出核心骨干阶段基本不依赖 `202.97.*` 而走 `59.43.*` 才是真双向 GIA（详查 [CN2 GIA 技术详解](/network/cn2-gia)）。

### 为什么如今大多数高质量机场主推「IEPL / BGP 中转」而不专门吹「CN2」了？

因为三网 BGP 境内入口 + 物理内网专线能够同时照顾到中国移动、联通和电信三大用户群体，并且内网隔离特征极难受公网晚高峰拥塞或随机协议限流影响；若个人自建单用追求极致公网直连，CN2 GIA 才更具探讨意义（详见 [中转 vs 直连百科](/network/direct-vs-transit)）。
