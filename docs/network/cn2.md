# 中国电信 CN2 网络百科

<AnswerBox question="什么是中国电信 CN2 网络？">
CN2 (China Telecom Next Generation Carrying Network，中国电信下一代承载网，自治域 AS4809) 是中国电信斥巨资建设的**高等级、低延迟、轻负载骨干网络**，专门用于政企专线、大客户与高级跨国数据传输，区别于平民级超重负荷的 163 骨干网 (AS4134)。
</AnswerBox>

---

## ⚖️ 163 骨干网 vs CN2 骨干网

- **163 骨干网 (AS4134，以 `202.97.*` 路由节点开头)**：承担了中国电信 90% 以上的普通民用宽带出海流量。晚高峰严重拥堵，丢包率高。
- **CN2 承载网 (AS4809，以 `59.43.*` 路由节点开头)**：采用先进的 MPLS 技术，全网轻载运行，单跳延迟低，丢包率极低。
