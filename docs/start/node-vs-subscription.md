# 节点与订阅的区别

<AnswerBox question="节点和订阅有什么区别？它们是什么关系？">
简单来说：**节点是一道菜，订阅是一整张菜单**。节点是远端真实的单台代理服务器；订阅是一个网络地址，客户端通过访问这个地址，可以一次性下载和更新一整组节点信息。
</AnswerBox>

---

## 📌 概念对比清单

| 对比项目 | 节点 (Node) | 订阅 (Subscription) |
| :--- | :--- | :--- |
| **物理形态** | 远端机房的一台实体服务器或云主机 | 一个由服务商维护的 HTTPS 网络链接 |
| **包含内容** | 单一的 IP、端口、协议（如 VLESS/Trojan）、密码 | 几十到上百个节点的数据集合，外加流量与到期信息 |
| **数量关系** | 一条订阅中通常包含几十个不同地区的节点 | 一个订阅链接包含一个节点集合 |
| **操作动作** | 在列表中点击某个节点即可将其设为当前连接出口 | 在客户端中输入订阅链接并点击「更新」以拉取全部节点 |
| **失效表现** | 单个节点超时不影响其他节点正常使用 | 订阅失效会导致所有节点无法拉取或无法更新 |

---

## ⚠️ 新手最容易犯的 3 个误区

1. **误区一：把单个节点的配置链接（如 `vmess://...`）当成订阅链接导入**
   - 结果：客户端提示“订阅格式错误”或“未解析到配置”。
   - 正解：单节点链接应当使用客户端的「从剪贴板导入节点」功能，而不是「添加订阅」。
2. **误区二：认为只要导入了订阅，就自动连上了网络**
   - 结果：依然无法上网。
   - 正解：导入订阅只是把“节点清单”下载到了本地，你还必须在清单中**选中一个可用节点**，并**开启系统代理或 TUN 模式**。
3. **误区三：节点超时了就到处删除重新导入**
   - 正解：遇到大部分节点超时时，通常只需在订阅列表上右键点击「更新订阅」，获取服务商推送的最新服务器 IP 即可，无需每次都手动删除重建。
