# 什么是机场？

<AnswerBox question="什么是中文网络中所说的“机场”？">
“机场”是中文互联网中对**商业化代理节点聚合服务商**的俗称。它通过部署分布在全球多地的服务器节点，并利用 Shadowsocks、VLESS、Trojan 等协议，为用户提供科学上网与跨国网络加速服务。
</AnswerBox>

---

## 🛫 名字是怎么来的？

“机场”这个词起源于早期的代理客户端 **Shadowsocks**。

1. Shadowsocks 的应用图标是一架纸飞机（Paper Airplane）。
2. 在 Shadowsocks 衍生出多节点管理工具（如 ShadowsocksR）后，管理和托管海量“纸飞机”节点的服务端被社区形象地戏称为“**机场**”。
3. 随后，提供这些代理节点配置订阅的服务提供商，便被广泛统称为“机场服务商”或简称“机场”。

## ⚙️ 机场的底层构成

一个完整的机场服务系统通常由以下三个核心部分构成：

```mermaid
graph TD
    User[用户终端 Clash / v2rayN] -->|订阅拉取| Panel[机场前台面板 / 订阅后端]
    User -->|加密流量| Entry[国内入口服务器 (BGP/专线)]
    Entry -->|跨境传输 (IEPL/公网中转)| Exit[境外落地服务器 (香港/日本/美国等)]
    Exit -->|直达访问| Target[Google / YouTube / GitHub]
```

1. **用户面板与订阅下发端**
   机场通常使用开源或自研的前端面板（如 SSPanel、V2Board 等），负责用户账户注册、套餐计费、流量统计，并将用户购买的节点信息打包为**订阅链接**。
2. **国内入口中转与接入服务器**
   为了保证连接稳定，优质机场通常会在国内不同省份部署 BGP 多线服务器作为数据入口，或者租用电信/联通的内网专线（如 IEPL / IPLC）。
3. **境外落地出口节点**
   位于全球各国家或地区（香港、日本、新加坡、美国、欧洲等）的云服务器或机房裸金属服务器，负责接收中转过来的流量并请求目标网站。

## 🎯 机场的核心用途

- **访问全球互联网公共资源**：顺畅访问 Google 搜索、学术论文库、GitHub 代码仓库等。
- **解锁跨国流媒体服务**：观看 YouTube 4K、Netflix 区域版权内容、Disney+ 等。
- **使用海外 AI 生产力工具**：稳定访问 OpenAI ChatGPT、Claude、Google Gemini 等受区域风控限制的服务。
- **跨国协同办公与学术研究**：海外邮件收发、远程服务器 SSH 运维与跨境业务通信。

## ⚠️ 使用机场时的安全与隐私常识

1. **端到端加密与传输安全**：只要你访问的是 HTTPS 网站，传输的数据在应用层始终由 SSL/TLS 证书加密，机场节点无法解密你的银行密码、支付信息或聊天正文。
2. **DNS 与访问域名可见性**：如果不开启防污染 DNS 或加密 DNS，机场节点或出口服务器可能看到你正在请求的域名（但看不到页面具体内容）。
3. **不要轻信免费公共节点**：免费公共节点由于运营者不明，可能存在恶意劫持未加密 HTTP 流量或注入广告的风险。

## ❓ 常见问题 FAQ

### Q1：机场等于 VPN 吗？
不等于。虽然它们都能改变对外 IP 地址，但传统 VPN（如 OpenVPN、IPsec）在操作系统底层建立全局虚拟网卡，流量特征明显且易被识别；而机场主要依托应用层/传输层代理协议与分流规则，更加灵活轻量。详情可查阅 [机场与传统 VPN 的区别](/start/airport-vs-vpn)。

### Q2：买了机场之后可以直接上网吗？
不能。机场只售卖节点数据和订阅链接。你还需要在手机或电脑上安装对应的**客户端软件**（例如 Clash Verge、v2rayN、Shadowrocket 等），将订阅链接导入客户端后方可连接使用。
