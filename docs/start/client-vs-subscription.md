# 客户端与订阅的关系

<AnswerBox question="客户端软件与订阅服务商是什么关系？">
客户端是**本地运行的工具软件**（如播放器），订阅是**服务商提供的节点数据**（如在线歌单）。它们完全解耦，同一个订阅链接可以在 Windows 的 Clash Verge、iOS 的 Shadowrocket 和 Android 的 v2rayNG 中同时导入使用。
</AnswerBox>

## 📻 生动比喻：音乐播放器 vs 在线歌单

为了彻底搞清两者的关系，可以参考以下对照模型：

```mermaid
graph LR
    Sub[你的机场订阅链接 (歌单URL)] -->|导入| Win[Windows: Clash Verge (播放器A)]
    Sub -->|导入| iOS[iOS: Shadowrocket (播放器B)]
    Sub -->|导入| Android[Android: v2rayNG (播放器C)]
```

- **客户端（播放器）**：由开源社区或独立开发者编写的软件（如 Clash Verge、v2rayN、sing-box）。负责在你的电脑或手机上建立本地代理服务、处理分流规则、管理网络流量。
- **订阅（歌单）**：由机场服务商提供的一段专属链接。里面记录了服务商提供的全部境外服务器节点地址。

## 🎯 关键认知要点

1. **客户端本身不包含任何免费网络流量**
   下载安装了 Clash 或 v2rayN 后，如果不导入有效的订阅或节点，软件没有任何代理功能。
2. **更换客户端不需要重新购买订阅**
   如果你在 Windows 上从 v2rayN 更换为 Clash Verge，只需将原本的订阅链接复制到 Clash Verge 中导入即可，订阅套餐依然有效。
3. **一个订阅通常支持多台设备同时使用**
   大部分机场服务商支持在多台设备（手机、电脑、平板）上导入同一条订阅链接，只需注意服务商套餐的“同时在线设备数限制”即可。
