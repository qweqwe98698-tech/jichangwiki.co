# 什么是订阅？

<AnswerBox question="什么是代理订阅？它和单独添加节点有什么区别？">
“订阅 (Subscription)”是将多个代理节点的服务器地址、端口、协议及密钥等参数，打包托管在一个固定的 **URL 网址** 中。客户端通过向该 URL 发起 HTTP 请求，即可一键批量下载或更新所有最新节点。
</AnswerBox>

---

## 💡 为什么需要订阅机制？

在早期阶段，用户需要手动一条一条将节点的 IP、端口、密码输入到客户端中。如果服务商更换了节点 IP、新增了国家地区或调整了端口，用户就必须重新手动修改每一个节点。

**订阅机制彻底解决了这一痛点**：

- **批量下发**：一个链接即可拉取数十甚至上百个节点。
- **动态更新**：服务商后端维护节点池，客户端只需点击「更新订阅」，即可自动同步最新的服务器地址与配置。
- **信息附带**：许多现代订阅链接在 HTTP Header 中还会附带用户的剩余流量、套餐到期时间等元数据。

---

## 🔗 订阅链接的典型形态

订阅链接本质上是一个普通的 HTTPS 网址，通常由服务商的域名加上一段加密的专属身份令牌（Token）构成：

```
https://sub.example.com/api/v1/client/subscribe?token=a1b2c3d4e5f67890
```

> [!WARNING] 安全提醒
> 订阅链接中的 Token 相当于你账户的代理访问通行证。请妥善保管，切勿在公开网络、群聊或公共论坛截图中泄露完整的订阅 URL。如果泄露，任何人都可以拉取你的节点并消耗你的流量配额。

## 📦 常见的订阅格式分类

不同的客户端支持不同的配置解析语法，常见的订阅下发格式包括：

| 订阅格式 | 主要支持客户端 | 格式特点 |
| :--- | :--- | :--- |
| **Clash YAML 格式** | Clash Verge, Stash, Clash for Windows | 包含完整的 Proxies、Proxy Groups 与 Rules 规则树 |
| **Base64 通用编码** | v2rayN, v2rayNG, Shadowrocket | 将单节点 URI (`vmess://`, `vless://`, `trojan://`) 进行 Base64 编码 |
| **sing-box JSON 格式** | sing-box, NekoBox | 标准 JSON 结构，结构严密，支持现代协议字段 |
| **SIP002 格式** | Shadowsocks 原生客户端 | 专门针对 Shadowsocks 协议的聚合格式 |

## 🔄 订阅的更新与维护周期

1. **建议更新频率**：建议开启客户端的「启动时自动更新」或设置每 24 小时更新一次。
2. **突发失效时的处理**：如果遇到大部分节点突然不可用，首先应手动执行一次「更新订阅」，以获取服务商切换后的最新可用入口与 IP。
3. **遇到更新报错**：若提示 404 或超时，请参阅 [更新订阅失败排查指南](/subscription/update-failed)。
