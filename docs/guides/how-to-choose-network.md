# 如何选择网络线路类型？

<AnswerBox question="直连、中转和 IEPL 专线应该怎么选？">
按预算与稳定性要求决定：① <strong>轻度使用/超低预算</strong>：选「公网直连」；② <strong>日常主流/平衡性价比</strong>：选「BGP 中转」；③ <strong>重度晚高峰办公/实时会议/跨境游戏</strong>：选「IEPL / IPLC 专线」。
</AnswerBox>

---

## 💰 预算与需求阶梯模型

- **入门级（10~20元/月）**：多为普通公网直连或单线中转，满足基本网页搜索、偶尔查资料。
- **主流级（20~50元/月）**：BGP 入口多线中转，晚高峰基本流畅，支持 4K 视频与主流流媒体解锁。
- **旗舰级（50~100+元/月）**：全 IEPL/IPLC 物理内网专线，晚高峰 0 丢包，原生家庭宽带解锁。
