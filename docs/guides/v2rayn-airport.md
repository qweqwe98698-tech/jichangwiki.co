# v2rayN 适用的节点服务选型考量

<AnswerBox question="v2rayN 用户挑选服务商应重点看什么？">
① 提供标准的 **V2Ray / Base64 通用订阅链接**；② 节点包含完整的 VLESS-Reality, Xray TLS 或 Trojan 配置；③ 支持通过代理与不通过代理双重订阅拉取。
</AnswerBox>

---

## 💻 考量重点

- **协议覆盖广度**：v2rayN 自身支持几乎所有协议，服务商若提供 Reality 或 Hysteria2 可以充分发挥 v2rayN 内核的极致性能。
- **真连接测速支持**：节点配置规范，支持 `Ctrl + O` 快速批量测速。
