# 选择指南导读

<AnswerBox question="面对繁多的客户端、协议和线路，应该如何做出最适合自己的选择？">
遵循「需求导向决策」：根据操作系统选**客户端**；根据网络丢包与抗封锁选**协议**；根据具体业务（游戏/流媒体/AI）选**节点地区**；根据预算与晚高峰要求选**线路（直连/中转/专线）**。
</AnswerBox>
