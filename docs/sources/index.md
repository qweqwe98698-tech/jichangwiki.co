1. **IETF RFC 国际互联网标准**：如 RFC 1928 (SOCKS5), RFC 8446 (TLS 1.3), RFC 9000 (QUIC) 等。
2. **开源内核官方项目仓库**：
   - Xray-core (XTLS / Project X)
   - Mihomo / Clash.Meta
   - SagerNet / sing-box
   - Hysteria (HyNetwork)
   - Shadowsocks-org (SIP 规范)
3. **主流客户端官方发布日志与文档**：Clash Verge Rev, v2rayN, Shadowrocket, Surge 等官方 Release 说明。
