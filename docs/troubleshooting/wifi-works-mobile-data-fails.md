# Wi-Fi 正常但手机 4G / 5G 流量无法使用排查

<AnswerBox question="为什么连着 Wi-Fi 一切正常，一出门切到 4G / 5G 手机流量就全部失联了？">
针对移动端特有的跨网断连故障，最快 3 步就能找到毛病：<br>
1. <strong>先检查有没有在系统设置禁用了代理软件使用「蜂窝移动网络」</strong>；<br>
2. <strong>从 Hysteria2 / TUIC 等 UDP 协议节点，切换回标准 <code>TCP 443</code> 端口的 Trojan / VLESS-Reality / SS 节点</strong>（移动蜂窝基站常重度限流 UDP 并发）；<br>
3. <strong>排查手机开启了 IPv6 优选导致 DNS 请求打不通</strong>（在代理软件内尝试关闭 IPv6 或调整默认 DNS）。
</AnswerBox>

## 一、移动端三大高发成因逐一解锁

### 1. 手机系统的「App 蜂窝数据权限」被误关（尤其是 iOS）
如果某次弹窗错点过“仅允许使用 WLAN”，软件一离开路由器信号就彻底断网：
- **iPhone / iPad**：进入 `设置 ➔ 蜂窝网络`（或对应 App 独立设置页），找到 **Shadowrocket / Stash / Loon / Quantumult X**，确认权限勾选为 **「无线局域网与蜂窝数据」**。
- **Android 手机**：进入 `设置 ➔ 应用管理 ➔ 流量使用状况 / 联网控制`，确保 **v2rayNG / NekoBox / Hiddify** 均已开启移动数据权限与后台无限制运行权限。

### 2. 蜂窝基站对 UDP 高频协议的 QoS 限流或丢包
国内不同地区、不同运营商（移动/电信/联通）的 4G/5G 基站网关策略比家里固定宽带严苛很多：
- 当你当前选中的节点恰好跑在基于 **UDP 传输的 Hysteria2 或 TUIC** 上、或者使用了冷门高位端口时，基站防火墙常常会主动丢包，出现「连 Wi-Fi 满速、切手机流量瞬间零网速」的现象。
- **立即可行的解决**：打开软件切换同一机场的 **Trojan、VLESS-Reality 或常规 443 端口 Shadowsocks** 节点（基于经典 TCP + TLS 握手伪装），极大多数情况下切换完即秒连。更多传输特性差异可见 [节点挑选与协议区别指南](/guides/how-to-choose-node)。

### 3. 移动数据默认分配 IPv6 引发的 DNS 兼容异常
目前手机 4G/5G 网络普遍开启了全栈 IPv6，而部分老旧机场节点或中转入口仅支持或正确配置了 IPv4 转发，一旦客户端优先按 IPv6 解析境外域名就容易卡死握手。
- **解决动作**：进手机代理客户端的设置页面（如 [Shadowrocket 设置](/clients/shadowrocket/) 或 [v2rayNG 教程](/clients/v2rayng/)），试着关闭软件设置里的「开启 IPv6」开关，或者开启「优选 IPv4」路由选项后再测。

## 二、快速对照：移动数据下的急救动作排序

| 检查顺序 | 对应操作 | 是否需要改节点 |
| :--- | :--- | :--- |
| **第 1 步** | 打开手机飞行模式 5 秒再关，确认代理 App「蜂窝网络权限」开启 | 否 |
| **第 2 步** | 在节点列表选一条 **TCP / 443 端口（如 Trojan / VLESS）** 的香港/新加坡线路 | 是 |
| **第 3 步** | 客户端设置里 **关闭 IPv6 开关**，并核对当前不是因为刚好离家时流量卡切换造成未更新订阅 | 否 |

## 常见问题解答（FAQ）

### 为什么手机在家里连 Wi-Fi 翻墙顺畅无比，一出家门切 4G/5G 移动流量就全断了？

常见于：① iOS/安卓屏蔽了软件走蜂窝数据权限；② 手机移动基站限流了基于 UDP 协议（如 Hysteria2）的线路；③ 移动网络的 IPv6 DNS 与当前客户端冲突。

### 切换到手机流量时，选用什么协议或端口的节点最不容易被运营商基站拦截？

在户外 4G/5G 移动数据下，采用标准 443 端口且走 TCP/TLS 伪装传输的节点（例如 `VLESS-Reality`、`Trojan` 或常规中转 `Shadowsocks`）适应性通常高于强依赖大发包 UDP 的直连线路。

### 在 4G/5G 下重启飞行模式依然连不上，去机场测试却显示一切正常怎么看？

可以尝试到客户端开启/关闭 IPv6 支持，并在同一机场内测试切换其他地区的备用入口节点；具体综合排错流程也可比照 [Shadowrocket 节点超时检查](/clients/shadowrocket/node-timeout)。
