# 节点测速全红 / 高延迟卡顿排查与优化指南

<AnswerBox question="节点虽然不是完全 Timeout，但测速延迟全在 500ms~2000ms+ 飘红、视频卡顿怎么改善？">
重点分清楚 <strong>「真全红卡顿」与「本地误测干扰」</strong>：先确保家里没人在满速下载 BT/网盘占用全部出口带宽；其次，避开地理物理绕路的欧美公网直连线路，优先切换带有 <strong><code>IEPL / 专线 / 中转</code> 标识的香港、台湾、日本、新加坡等亚太近区节点</strong>。<br>
（如果是整排节点连延迟数值都没有、全部直接报错 <code>Timeout / -1</code>，请改走：<a href="/troubleshooting/all-nodes-timeout">全节点超时 Timeout 急救手册</a>。）
</AnswerBox>

## 一、延迟飙红高丢包的 4 大真实物理成因

### 1. 光纤地理距离与绕路问题（不可抗力物理延迟）
光在光纤玻璃介质中的传输速度大约只有每毫秒 200 公里（含路由转发开销）。
- 中国大陆 ➔ 香港/台北：理想直连或专线通常仅需 **15ms ~ 60ms**；
- 中国大陆 ➔ 美西：哪怕直连无拥塞，物理往返也必须花费 **130ms ~ 170ms**；一旦遇到劣质路线绕欧洲或绕 NTT，延迟轻松破 **300ms~500ms+**。

### 2. 每晚 20:00~23:00 国际骨干网晚高峰拥堵
每年大量低成本直连机场白天看似飞快，但一到晚上八点用网高峰期，普通民用国际出口严重塞车、丢包率剧增，TCP 重传导致客户端测速数值动辄从 80ms 飙升至 1000ms 以上并呈大面积红色。详细骨干网拥堵机理可见 [CN2 与 163 骨干网层级科普](/network/cn2)。

### 3. 本地客户端并发测速引发短暂卡顿或误判
当你在一两百个节点的列表上疯狂点「一键全部测速」时，客户端同时向上百个远端服务器发起 URL/TLS 请求，如果此时路由器性能较弱、或本身宽带上行很小，会造成本地排队阻塞，“越测延迟越高”，但单独选中主力节点打开网页实际丝滑无比。

### 4. 本地高占用后台（网盘同步 / P2P 下载 / Wi-Fi 干扰）
开着百度网盘满速上传、Steam 更新游戏或使用信号很差的 2.4GHz 穿墙 Wi-Fi 时，本地出口延迟就已经被塞满 400ms，哪怕用顶级 IEPL 专线节点测试照样显示发红。

## 二、降延迟与提流畅度的实战挑选策略

| 操作检查步骤 | 具体怎么做 | 预期改善 |
| :--- | :--- | :--- |
| **1. 改用亚太近邻与中转/专线节点** | 优先切选香港、台湾、新加坡、日本（带 `[IEPL]`、`[专线]` 标识） | 大幅降低往返物理延迟与晚高峰丢包率（原理见 [如何挑选节点](/guides/how-to-choose-node)） |
| **2. 排查测速 URL 响应误差** | 把客户端测速 URL 换成 `http://www.gstatic.com/generate_204` 测试 | 消除因为测速目标站反应慢带来的假延迟虚高 |
| **3. 暂缓大带宽后台并测试有线/5G Wi-Fi** | 关闭下载软件，靠近路由器改用 5GHz 频段或网线直连 | 验证究竟是自家内网延迟还是境外链路问题 |
| **4. 升级基础设施型线路（如果预算极低全红无解）** | 若目前使用的是几元包年的纯公网直连超售机场，可评估升级主流 [IEPL 专线服务](/recommend/iepl-airports) 或先用 [高性价比月付套餐](/navigation/monthly-pay) 对照体验 | 从线路底层避开普通公网国际出口高峰塞车 |

## 常见问题解答（FAQ）

### 节点测试全部显示几百上千毫秒「全红」，和显示「Timeout」是一回事吗？

不完全一样。`Timeout` 表示根本没握上手彻底中断（需要先检查时钟、核心与更新订阅）；而飘红代表链路仍连着但极其拥堵、绕路严重或遇到高丢包。排查完全连不上看 [全节点超时手册](/troubleshooting/all-nodes-timeout)。

### 为什么日本和美国节点经常显示 300ms~600ms，甚至偶尔发红？

受光缆物理往返限制与路由绕路影响，普通直连美西和某些日本绕路机器经常落在几百毫秒；另外每晚 20:00-23:00 骨干网拥堵会大幅推高非专线线路的重传延时。

### 换了好几条还是全红卡顿，怎么立刻挑出能流畅看视频的低延迟节点？

优选亚太近区且拥有企业内网跨境架构（IEPL/优质 BGP 中转）的线路，详情挑选标准见站点高点击实用手册：[节点挑选完全指南（如何看懂地区、倍率与测速）](/guides/how-to-choose-node)。
