# 节点测速全红 / 延迟极高排查指南

<div class="jw-badge jw-badge-red">高延迟异常</div>

<AnswerBox question="节点测速虽然不是 Timeout 但延迟全部几千毫秒飘红怎么办？">
首先确认是否处于**晚高峰公网拥堵期**；检查当前使用的是否为**跨国公网直连线路**（直连美国延迟通常在 180~250ms，直连欧洲在 200~300ms）；切换为**香港/日本/新加坡的优质中转或 IEPL 专线节点**。
</AnswerBox>

---

## 🔍 核心原因与对策

1. **地理物理延迟限制**：光信号在光纤中的传播速度约为每毫秒 200 公里。国内到美国西海岸往返物理极限约为 130~160ms，若走直连线路且遇到路由绕路，显示 200~400ms 属于正常物理范围。
2. **晚高峰骨干网拥堵**：每晚 20:00~23:00，公网国际出口拥塞，直连节点丢包率上升导致测速重传延迟飙升。
3. **优化建议**：优先选用带有 `[IEPL]`、`[专线]` 或 `[中转]` 标签的近场节点（香港、台湾、日本）。
