# 客户端完全无法连接 / 崩溃报错排查

<div class="jw-badge jw-badge-amber">启动异常</div>

<AnswerBox question="客户端完全打不开或启动后立即闪退怎么办？">
优先以「管理员身份运行」；检查端口冲突（如 7890/10808 端口被占用）；检查杀毒软件是否拦截了内核进程；检查系统是否缺少必要的 VC++ 或 .NET 运行库。
</AnswerBox>

---

## ⚡ 快速检查清单

1. **以管理员身份启动**：右键点击客户端图标，选择「以管理员身份运行」。
2. **排查端口占用**：在客户端设置中修改本地端口号（如改为 17890 / 20808）。
3. **查看错误日志**：打开客户端的「日志 (Log)」页面，定位具体报错信息。
4. **重新解压完整包**：若核心丢失，重新下载带有 `With-Core` 的完整客户端压缩包。
