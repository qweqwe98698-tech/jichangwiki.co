# 手机正常但电脑无法上网排查指南

<AnswerBox question="同一个账号订阅在手机好好的，为什么一换到 Windows / macOS 电脑上就完全连不上？">
因为电脑操作系统环境和手机机制迥异，重点核对这 4 步（命中率超过 90%）：<br>
1. <strong>立即同步电脑系统时间</strong>（Windows 极易慢几分钟，导致所有节点 TLS 握手报错）；<br>
2. <strong>确认客户端「系统代理」总开关真的拨开了</strong>（光导入节点默认不接管浏览器）；<br>
3. <strong>停用浏览器历史代理插件与残留加速器</strong>；<br>
4. <strong>排查电脑安全软件防火墙拦截了代理核心</strong>（或试切换开启 TUN 模式验证）。
</AnswerBox>

## 一、手机与电脑环境究竟差在哪？

很多新手看到手机上好好的，就误以为电脑端坏掉了或者机场在限电脑端。其实同一账号两端机制主要存在三大区别：
- **时区/时钟精准度**：手机实时由蜂窝基站授时几乎零偏差；电脑主板 CMOS 或双系统切换非常容易把系统时间拖慢几十秒甚至几个小时，加密协议立刻全盘拒连。
- **VPN 接管层级**：手机 App 一旦点亮 VPN 开关就是全机透明转发；电脑端客户端默认需要靠 **「系统代理 (System Proxy)」** 告知浏览器往本机端口 `7897 / 10809` 发请求，一旦浏览器安装了独立扩展插件，系统代理就被绕过去了。
- **端口及后台软件复杂度**：电脑经常残留旧加速软件、微软 Defender 拦截规则、校园认证客户端或杀毒软件 Web 扫描，这些环境在手机上很少出现。

## 二、电脑端按优先级执行的 5 步快速修复

### 第一步：点击 Windows/Mac 联网时钟同步（必查！）
- **Windows 10/11**：按 `Win + I` 打开系统设置 ➔ `时间和语言` ➔ `日期和时间` ➔ 确认开启「自动设置时间」并点击一次 **「立即同步」**。
- **macOS**：进入系统设置 `通用 ➔ 日期与时间`，确保「自动设置日期与时间」及定位时区均已启用。

### 第二步：确定客户端总开关 & 核心处于激活态
- **Clash Verge Rev**：进软件主页找到 **「系统代理 (System Proxy)」** 按钮，确保其变为亮色打开状态（并推荐把顶部模式保持在 **规则模式 Rule**）；详细打不开网页排错见 [Clash Verge 无法上网排查](/clients/clash-verge/cannot-open-websites)。
- **v2rayN**：查看电脑右下角系统托盘小图标是否为**红色（自动配置系统代理）**；若仍为蓝色清除状态，右键图标设为「自动配置系统代理」。参考 [v2rayN 打不开网页处理](/clients/v2rayn/cannot-open-websites)。

### 第三步：清空 Chrome / Edge 的冗余代理插件与旧系统变量
很多电脑曾用过免费浏览器拓展（如某某加速器扩展、SwitchyOmega 错设规则等）。只要浏览器启用了强控制权插件，客户端开不开系统代理它都不理。
- 暂时关闭所有代理类浏览器扩展，甚至先开一次**全新无痕窗口或另一款干净浏览器**对比访问是否通畅。

### 第四步：检查杀软与 Windows 防火墙白名单
确保 `verge-mihomo.exe` 或 `xray.exe` 未被防御程序静默截断，或尝试换一个高端口（例如 `17897`）避开公司安全软件监控。

### 第五步：对于不走系统代理的桌面软件，开启 TUN 虚拟网卡测试
部分终端命令（Git/Node/npm）、老版本桌面应用不会去读 Windows 系统代理。如果您是这类应用在电脑连不上而浏览器其实能上，请正确安装 Service Mode 后尝试启用客户端内的 [Clash Verge TUN 模式](/clients/clash-verge/tun-mode) 接管全机流量。

## 常见问题解答（FAQ）

### 同一个机场订阅，为什么手机秒连、Windows 电脑却所有节点超时或打不开网页？

最常栽在：① 主板时钟漂移超过 60 秒导致加密校验全部被拒；② 只导入订阅忘了打开「系统代理」总开关；③ 浏览器开着其他代理插件或旧加速器把系统代理架空了。建议结合 [全节点超时 Timeout 手册](/troubleshooting/all-nodes-timeout) 对照日志。

### Clash Verge 上测速明明有正常几十毫秒延迟，电脑浏览器依然一直转圈或打不开谷歌怎么修？

节点本身是通的！重点检查「系统代理」开关是否真的点亮，其次关掉 Chrome / Edge 里以前安装过的第三方代理扩展，并在客户端日志页查看请求到底走的是哪条线路规则。

### 电脑开了 VPN 或者 TUN 模式反而不如直连快，甚至全部站点都失效了？

检查是否同时开启了其它游戏加速器、企业 VPN 或错填了无效自定义 DNS；建议排除时只保留单一客户端的默认规则模式测试。
