# NekoBox 客户端知识中心

<AnswerBox question="什么是 NekoBox？">
NekoBox 是一款基于 sing-box 开源核心开发的跨平台代理客户端，主要活跃于 Android 平台（NekoBox for Android）。它以原生的 Material You 现代 UI 和对最新代理协议（VLESS-Reality, Hysteria2）的极速支持深受技术用户喜爱。
</AnswerBox>

---

## 🚀 核心特性

- **现代 Material You 界面**：完美适配 Android 12+ 动态取色主题。
- **sing-box 原生内核**：支持快速解析并加载各类包含复杂分流规则的 sing-box JSON 订阅。
- **全协议支持**：支持 Shadowsocks 2022、TUIC v5、Hysteria 2、WireGuard 等。
