# Loon (iOS) 知识中心

<AnswerBox question="什么是 Loon？">
Loon 是运行在 iOS 平台上的现代网络工具（App Store 售价 $5.99 美元）。它在保持高性能与低耗电的同时，提供了开箱即用的强大**插件体系 (Plugin)** 与直观的可视化规则编辑器。
</AnswerBox>

---

## 💡 核心特性

- **模块化插件系统**：支持一键安装社区插件，自动组合脚本、重写与分流规则。
- **可视化节点与策略管理**：拖拽式策略组配置，操作门槛显著低于纯文本编辑。
- **现代协议支持**：支持 Shadowsocks, VMess, VLESS, Trojan, Hysteria 2, WireGuard 等。
