# v2rayN 系统代理设置与清除

<AnswerBox question="v2rayN 如何开启系统代理？托盘图标颜色代表什么？">
在 v2rayN 底部状态栏将「系统代理」下拉框切换为「自动配置系统代理」。托盘图标变成**红色 V 字**表示系统代理已开启；图标为**深蓝色 V 字**表示系统代理已清除（未开启）。
</AnswerBox>

---

## 🎨 托盘图标颜色与状态对应

| 图标颜色 | 系统代理状态 | 说明 |
| :--- | :--- | :--- |
| 🔴 **红色 V** | **自动配置系统代理** [已开启] | Windows 系统代理已生效，浏览器流量自动走 v2rayN |
| 🔵 **深蓝色 V** | **清除系统代理** [未开启] | 系统未设代理，仅手动配置了 10808/10809 端口的应用走代理 |
| 🟣 **紫色 V** | **TUN 模式开启中** | 全局虚拟网卡模式已激活 |

---

## ⚠️ 关机前或退出时的注意事项

请始终通过正常方式右键托盘图标点击「退出」来关闭 v2rayN。退出时，程序会自动将 Windows 系统代理还原；如果电脑突然断电或强行杀掉进程，可能导致系统代理残留，开机后浏览器提示“代理服务器连接失败”。
- **修复方法**：重新启动一次 v2rayN，并在底部将系统代理设为「清除系统代理」即可恢复。
