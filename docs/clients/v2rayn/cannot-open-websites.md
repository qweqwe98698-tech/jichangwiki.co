# v2rayN 已连接但打不开网页

<AnswerBox question="v2rayN 测速正常但打不开网页？">
检查任务栏右下角 v2rayN 图标是否为红色（系统代理必须开启）；检查底部路由是否选了「全局」且该节点被国外目标封禁；检查浏览器是否安装了第三方代理插件接管了流量。
</AnswerBox>

---

## 🚦 快速恢复指南

1. **确认系统代理真正激活**：底部「系统代理」必须切换为「自动配置系统代理」，托盘图标为红色。
2. **检查路由模式**：底部路由建议选择「绕过大陆」。
3. **排查浏览器代理插件**：若安装了 SwitchyOmega，在扩展中切换为「系统代理」模式。
4. **更换为真连接可用的节点**：按 `Ctrl + O` 重新测速，选中延迟数值正常的节点并按回车设为活动服务器。
