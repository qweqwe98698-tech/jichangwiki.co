# v2rayN 真连接延迟与测速方法

<AnswerBox question="v2rayN 中哪种测速方式最准确？快捷键是什么？">
最准确的测试方法是「**测试服务器真连接延迟**」，快捷键为 **Ctrl + O**。它会实际通过节点与 Google/Cloudflare 握手并返回真实 HTTP 响应时间；只有数值显示为具体毫秒数（如 85ms）才代表节点切实可用。
</AnswerBox>

---

## ⚡ 三种测速模式对比与快捷键

| 测速类型 | 快捷键 | 测试原理 | 结果参考价值 |
| :--- | :--- | :--- | :--- |
| **测试服务器真连接延迟** [强烈推荐] | **Ctrl + O** | 客户端向远端真实发送 HTTP 请求并测量返回时间 | **最高**（能测出该节点能否真正打开网页） |
| **测试服务器延迟 (Ping)** | **Ctrl + R** | 仅测试本地到节点服务器入口的 TCP 握手时长 | **较低**（中转节点仅代表国内入口延迟，不能反映出口好坏） |
| **测试服务器速度 (下载测速)** | **Ctrl + T** | 下载测试小文件测量最大并发下行带宽 | **适中**（会消耗实际套餐流量，不建议频繁全选测试） |
