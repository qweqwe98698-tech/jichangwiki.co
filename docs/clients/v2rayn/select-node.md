# v2rayN 活动服务器选择与切换

<AnswerBox question="v2rayN 怎么切换当前正在使用的节点？">
在主界面节点列表中，单击选中目标节点，按下键盘 **Enter (回车键)**，或者鼠标右键该节点选择「**设为活动服务器**」。该节点文字会变为加粗高亮或左侧出现勾选标志。
</AnswerBox>

---

## 🧭 节点选择与排序技巧

1. **一键按延迟排序**：完成 `Ctrl + O` 真连接测速后，点击列表表头的「真连接延迟」列，所有可用节点会自动按延迟从小到大升序排列。
2. **批量删除不可用节点**：选中显示 `-1` 或 `Timeout` 的节点，按下 `Delete` 键即可清理异常节点。
3. **托盘右键快速切换**：在任务栏右下角右键 v2rayN 图标，在「服务器」子菜单中可以直接点击切换节点，无需打开主窗口。
