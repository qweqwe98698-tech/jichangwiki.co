# v2rayN 节点全部超时（真连接全 `-1`）解决办法

<AnswerBox question="v2rayN 点击真连接测试清一色显示 -1 或 Timeout 怎么办？">
按照这 4 步一分钟排完 95% 的真连接报错：<br>
1. <strong>立即校准 Windows 系统时钟</strong>（按 <code>Win + I</code> 进日期和时间点「立即同步」，误差超 60 秒即被加密握手拒绝）；<br>
2. <strong>检查 <code>bin/xray/xray.exe</code> 核心是否被杀毒软件误杀</strong>（最容易忽略）；<br>
3. <strong>执行「更新全部订阅(不通过代理)」</strong>拿回机场换绑后的新 IP 与密码；<br>
4. 登录官网核对账号未过期（更多通用定位流程参考：<a href="/troubleshooting/all-nodes-timeout">全节点超时 Timeout 深度排查</a>）。
</AnswerBox>

## 一、核心诊断四步走（按排查命中率排序）

### 1. 第一嫌疑：Windows 系统时间与网络不同步
VLESS / VMess / Trojan 等主流加密协议在校验时间戳时有极其严格的容错阈值（一般不允许与服务器标准时间相差超过 60~90 秒）。哪怕只是快了 2 分钟、甚至年份错成双系统切换时的错误时间，都会导致 **Tcping 正常有延迟、但真连接测试全部 `-1`**。
- **修复**：`Win + I` ➔「时间和语言」➔「日期和时间」➔ 开启自动设置时间并强点一次 **「立即同步」**。如果是双系统用户建议统一时钟基准。

### 2. 第二嫌疑：`xray.exe` 或 `sing-box.exe` 被杀软隔离
Windows 安全中心或第三方杀软有时会误报拦截代理内核可执行文件，造成 v2rayN 的前端皮还在开着、底层干活的引擎却已经丢了，结果任何操作全超时。
- **自查路径**：打开你存放 v2rayN 的根目录 ➔ 检查 `bin\Xray\xray.exe` 与 `bin\sing_box\sing-box.exe` 是否健在；同时查看程序底部“信息窗口”有没有出现核心未找到或拒绝访问报错。
- **修复**：进 Windows 安全中心「病毒和威胁防护 ➔ 管理设置 ➔ 添加排除项」，把 v2rayN 文件夹整体添进去再重新解压补全 Core 核心。

### 3. 第三嫌疑：旧订阅信息过时（机场换节点 IP 或账户重置）
一旦服务商后端调整了入口服务器 IP 或端口配置，你本地旧订阅拉回来的全是指向空机器的地址：
- 确认顶部勾选或右键将系统代理切到清除 ➔ 点击 **`订阅分组 ➔ 更新全部订阅(不通过代理)`**。若更新也直接报错，立刻转去 [v2rayN 更新订阅失败排查](/clients/v2rayn/subscription-update-failed)。

### 4. 第四嫌疑：老版客户端内核不识别新式传输协议
如果你的机场近年刚刚把旧节点集体替换成 `VLESS-Reality`、`Hysteria2` 或启用最新指纹参数，几年前下载的 v2rayN v5.x 或陈旧 `xray-core` 无法完成新握手：
- 升级使用最新版官方 v2rayN 及最新 core；同时记得确认机场套餐账户尚未耗尽额度（见 [订阅过期判断](/subscription/expired)）。

## 二、真连接测试也有 `-1`，需排查是不是“真不通”还是“测试网址锅”

| 现象细节 | 说明与建议检查项 |
| :--- | :--- |
| **所有地区真连接都是 `-1`，且换手机热点照样不通** | 检查上面 1~4 步 + 登录机场官网确认服务器未大面积维护 |
| **本地延迟测出全 `-1`，但选一条主力直接开系统代理却能刷开网站** | 进入 `设置 ➔ 参数设置 ➔ v2rayN 设置 ➔ 测速网址`，将其改用如 `https://www.gstatic.com/generate_204` 后重测 |
| **家里宽带全 `-1`，连手机 5G 热点马上满血变成 `60ms`** | 家里路由器或光猫出现地区性端口阻断/污染，可优先尝试开备用机场或切换软件走 **Clash Verge + Mihomo 生态** 对比测试 |

## 常见问题解答（FAQ）

### v2rayN 测延迟时「Tcping 延迟」正常有数字，为什么一测「真连接」全部显示 -1？

Tcping 只测客户端能不能连接到服务器端口（TCP 握手），并不验证加解密能否通过；真连接才真正发起加密请求。出现 Tcping 通但真连接全 `-1`，最高发原因是电脑系统时钟偏差大于 60 秒、内核损坏或者机场服务器密钥随账户状态更新了，需同步时间与重拉订阅。

### 刚刚把电脑装好安全软件或 Windows 更新，v2rayN 启动后全部超时怎么办？

极其常见的是安全软件悄悄把 `bin/Xray/xray.exe` 隔离删掉了。需将整个 v2rayN 文件夹加入杀软排除项白名单，并重新补回带 Core 的完整版核心文件。

### 选好有正数延迟的节点并按了回车，为什么 Chrome 还是打不开网页？

说明底栏「系统代理」可能仍留在未开启状态、或浏览器装了其它冲突代理插件；排查方式见通用 [全节点超时深度对照](/troubleshooting/all-nodes-timeout)。
