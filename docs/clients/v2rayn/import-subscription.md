# v2rayN 导入订阅链接与单节点

<AnswerBox question="v2rayN 怎么添加机场订阅链接？">
在 v2rayN 顶部菜单栏点击「订阅分组」→「订阅分组设置」；点击「添加」；在「可选网址(url)」一栏粘贴你的订阅链接；在「备注」中输入机场名；点击「确定」后，点击菜单「订阅分组」→「更新所有订阅(不通过代理)」即可。
</AnswerBox>

## 📋 导入单节点配置（从剪贴板导入）

如果你拥有朋友分享的单个节点链接（如以 `vless://`、`vmess://`、`trojan://`、`ss://` 开头的字符串）：
1. 复制该节点字符串到剪贴板。
2. 打开 v2rayN 主界面，直接按下键盘快捷键 **Ctrl + V**（或点击顶部菜单「服务器」→「从剪贴板导入批量 URL」）。
3. 节点即可瞬间导入到当前列表中。
