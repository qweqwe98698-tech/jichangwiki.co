# v2rayN 导入订阅链接与单节点操作教程

<AnswerBox question="Windows 下 v2rayN 怎么导入机场订阅地址并开启规则分流？">
完整 4 步即可通网：<br>
1. 去机场后台复制<strong>「V2Ray / 通用订阅（Base64）」</strong>（切记不要用 Clash 订阅）；<br>
2. 点 v2rayN 顶部<code>订阅分组 ➔ 订阅分组设置 ➔ 添加</code>，填备注并粘贴 URL 点确定；<br>
3. 点菜单<code>订阅分组 ➔ 更新全部订阅(不通过代理)</code>同步所有节点；<br>
4. 回车激活任意测速正常节点，将软件最底栏切换为 <strong>「自动配置系统代理」</strong> 与 <strong>「绕过大陆(Whitelist)」</strong> 路由规则。
</AnswerBox>

## 二、导入单节点分享链接的快捷操作（Ctrl + V）

如果你只需要临时测试朋友发来的一条或几条单节点文本（以 `vless://`、`vmess://`、`trojan://`、`ss://`、`hy2://` 开头）：
1. 在聊天窗口或笔记选中完整协议链接右键复制；
2. 点击聚焦回到 v2rayN 主列表空白区，直接键盘按下 **`Ctrl + V`**（或者进菜单 `服务器 ➔ 从剪贴板导入批量 URL`）；
3. 单条节点会被立即归进当前分组列表。

## 常见问题解答（FAQ）

### v2rayN 可以直接导入 Clash 订阅链接吗？

通常不可以。v2rayN 默认读取通用 Base64 节点列表；如果机场下发的是带策略组与规则的完整 Clash YAML 文件，v2rayN 直接作为订阅导入很容易解析为空或格式失败，必须在机场后台复制通用 / V2Ray 订阅格式。

### 新电脑想下载安全无毒的 v2rayN，应该去哪里找包含核心的版本？

请务必前往开源项目官方 Release（2dust/v2rayN）并优先选用带 core 的完整压缩包（如 `v2rayN-windows-64-With-Core`），解压到全英文路径下运行，避开国内陌生打包下载站。

### 节点导入成功后怎么测试哪条路线最稳最快？

全选列表按快捷键 `Ctrl + R`（真连接延迟测速），注意重点看有正数 ms 返回而不是 `-1` 或超时的路线，更深入的选线指标判断可参考 [如何科学挑选与测试机场节点](/guides/how-to-choose-node)。
