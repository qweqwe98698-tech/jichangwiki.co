# v2rayN 更新订阅与自动更新策略

<AnswerBox question="v2rayN 更新订阅应该选「通过代理」还是「不通过代理」？">
平时建议优先选择「**更新所有订阅(不通过代理)**」；如果订阅链接所在的服务器域名已被污染或无法直连，则先选中一个可用节点并开启系统代理，再选择「**更新所有订阅(通过代理)**」。
</AnswerBox>

---

## 🔄 两种更新模式原理

- **更新所有订阅(不通过代理)**：本地网络直接发起 HTTP GET 请求拉取配置。避免因当前节点不可用导致订阅更新陷入死锁。
- **更新所有订阅(通过代理)**：请求通过当前选中的活动节点转发。当机场订阅服务器被国内防火墙阻断时必须使用此项。

---

## ⏰ 配置自动定时更新

1. 点击菜单栏「订阅分组」→「订阅分组设置」。
2. 勾选右上角的「自动更新 (Auto Update)」。
3. 可以在「基础设置」中指定每日自动更新的时间段，保持节点库永远处于最新状态。
