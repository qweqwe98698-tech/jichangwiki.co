# Surge 知识中心

<AnswerBox question="Surge 为什么被公认为 Apple 平台的旗舰级网络工具？">
Surge 是一款面向网络工程师与高阶开发者的商业网络调试与代理工具。它不仅拥有极致的性能优化与稳定性，还具备工业级的 HTTP/HTTPS 抓包、MitM 解密、本地 DNS 映射与复杂 JavaScript 脚本分流能力。
</AnswerBox>

---

## 💎 核心专业能力

1. **深度网络捕获与调试 (Packet Capture)**：实时查看每个网络连接的 TCP 握手耗时、TLS 协商过程与请求报文体。
2. **增强模式 (Enhanced Mode)**：在 macOS 层面以最低开销接管整机所有流量。
3. **Surge Ponte**：利用 WireGuard 与私有协议实现跨设备异地私网穿透与远程代理。
