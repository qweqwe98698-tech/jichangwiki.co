# v2rayNG (Android) 知识中心

<AnswerBox question="v2rayNG 适合什么场景？安卓手机怎么快速配置？">
v2rayNG 是 Android 平台最受欢迎的开源代理客户端。它内置 Xray 核心，完美支持 VLESS、VMess、Trojan、Shadowsocks 等协议。点击右上角「+」即可通过扫码或剪贴板导入订阅，点击右下角 V 字图标即可一键连接。
</AnswerBox>

---

## 📱 核心功能特性

1. **分应用代理 (Per-App Proxy)**：在左侧抽屉菜单中进入「分应用代理」，可以自由勾选哪些 App 走代理（如 YouTube、Twitter、Chrome），哪些 App 绝对直连（如微信、美团、银行类 App）。
2. **丰富的订阅支持**：支持 Base64 通用订阅、单节点快速导入与批量延迟测速。
3. **分流路由模式**：在设置中可切换「绕过局域网及大陆地址 (Bypass LAN and Mainland)」，省电省流量。
