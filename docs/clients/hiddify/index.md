# Hiddify 跨平台客户端知识中心

<AnswerBox question="Hiddify 客户端有什么特点？适合哪些用户？">
Hiddify 是一款基于 Flutter 构建的开源跨平台客户端（底层使用 sing-box 核心）。它在 Windows、macOS、Android、iOS 拥有完全一致的现代化极简 UI，支持自动选择最快节点与零门槛订阅导入，适合追求极简体验的跨设备用户。
</AnswerBox>

---

## 🌟 核心优势

- **真跨平台一致性**：在电脑与手机上拥有一模一样的操作逻辑与界面布局。
- **内置智能模式**：提供「Smart / 智能」模式，自动在后台探测最低延迟的节点并无缝切换。
- **广泛的协议兼容**：依托底层 sing-box 核心，原生支持 VLESS-Reality、Hysteria2 与 SSH 等丰富协议。
