# Shadowrocket (小火箭) 节点全部超时 (Timeout) 排查

<AnswerBox question="小火箭点击连通性测试全部显示 Timeout / 全红怎么一分钟修好？">
依次执行这 4 步最有效：<br>
1. <strong>关闭顶部开关 ➔ 在主页按住下拉屏幕强制更新订阅</strong>（老 IP 可能已由服务商更换）；<br>
2. <strong>检查 iPhone「设置 ➔ 通用 ➔ 日期与时间」开启「自动设置」</strong>（防 TLS 时间校验拒绝）；<br>
3. <strong>排查是否正连着校园网 / 公司限流 Wi-Fi，临时切换 4G/5G 蜂窝对比测试</strong>；<br>
4. 确认节点余量未用尽（必要时参阅 <a href="/troubleshooting/all-nodes-timeout">全节点超时通用深层排查手册</a>）。
</AnswerBox>

## 一、快速排查清单（从最高概率开始）

### 1. 下拉刷新订阅（IP 更换与维护同步）
机场遇到网络波动或入口机器调整，会在后台更换最新域名解析 IP。如果你开启小火箭后几个月不点刷新，本地捏着的还是早已下线的旧地址，自然 100% 全部超时。
- **操作**：先拨关闭顶部的连接开关，手指在主页空白位置 **用力向下拉动一次列表**，看到上方加载进度条走完即完成刷新；若下拉报红字失败，对照 [小火箭更新订阅失败排错](/clients/shadowrocket/subscription-failed)。

### 2. 校准 iPhone 系统时间（关键硬门槛）
现代 AEAD 加密协议（SS / VMess / Trojan / VLESS-Reality）要求移动端与服务器的时间戳误差严格控制在 ±60 秒内。只要手机时间手动调过或时区不对，**所有节点无一例外会握手超时**。
- **操作**：进系统 `设置 ➔ 通用 ➔ 日期与时间`，将「自动设置」关闭再重新打开；如有必要检查时区是否准确在北京/当前所在城市。

### 3. 切换「连通性测试」目标网址测试是否“假超时”
有些时候节点本身通畅，但默认测速 URL 在当前网络环境反应慢或被丢包：
- 进入小火箭右下角 `设置 ➔ 连通性测试`：
  - 将类型从 ICMP（Ping 容易被服务器关掉或误导）改为 **TCP 或 CONNECT / URL 测试**；
  - 将测速 URL 替换为 `http://cp.cloudflare.com/generate_204` 或 `http://www.gstatic.com/generate_204`。
  - 退回主页再点一次「连通性测试」对比效果。

### 4. 检查机场余量与“全局路由”模式设置
- **余额验证**：翻开订阅卡片或官网看当月配额是不是用尽清零，见 [过期与流量耗尽判断](/subscription/expired)。
- **路由检查**：确认主界面「全局路由」处于 **配置** 或调试用的 **代理**，而非选成纯直连模式；检查对应手机 Wi-Fi 的 `HTTP 代理` 一栏处于「关闭」。

## 二、切换蜂窝测试依然全红且确认非账户到期？

如果上面四项（更新订阅 + 自动时间 + 更换蜂窝 5G + 核对未超额）做完后，**全部节点还是真连接超时、海外网页全打不开**：
- 大概率属于该机场主力大面积维护停服、或该服务商线路遭遇大规模单向阻断。
- 平时建议按照 [备用及应急方案梳理](/navigation/backup) 留一条高性价比按量付费备用通道；同时可参考 [Clash Verge 节点 Timeout 排查](/clients/clash-verge/node-timeout) 与 [全节点超时通用清单](/troubleshooting/all-nodes-timeout) 对比检查电脑端连通状况，快速判别是单台手机故障还是全线问题。

## 常见问题解答（FAQ）

### 小火箭测速全部显示黄色或红色 Timeout，但实际还能打开网页是怎么回事？

偶尔部分机场服务器为了防探测禁用了 ICMP/特定接口响应，导致假性显示 `Timeout`。直接挑一条主力低负载地区打开顶部总开关并用 Safari 实际加载境外页面最为准确；同时建议进小火箭把测试方式设为 URL / CONNECT 测试。

### 改了测速网址依然全军覆没且确认无法翻墙，最先排查哪一步？

最先关掉主开关下拉更新一次订阅获取机场最新换绑 IP；第二步进入 iPhone「设置 ➔ 通用 ➔ 日期与时间」确认开启了「自动设置」，防止加密时间戳校验拒绝。

### 在公司 Wi-Fi 全部超时，切换手机流量 5G 却瞬间恢复正常怎么回事？

典型说明公司或校园局域网路由器存在严格防火墙拦截或屏蔽特定端口/协议，与机场和手机软件本身无关；另外也记得检查一下该 Wi-Fi 详情页里是否误留了手动 HTTP 代理。
