# Shadowrocket 节点测速与智能选择

<AnswerBox question="小火箭如何测试节点延迟？哪个数值最准确？">
在小火箭首页点击「连通性测试 (Connectivity Test)」，小火箭会测量每个节点的真实 HTTP 响应时间。选择延迟在 50~150ms 之间且显示为绿色/黄色的节点即可。
</AnswerBox>

---

## 🚦 测速方式与指标解读

1. **连通性测试 (HTTP Ping)**
   - 点击「连通性测试」后，小火箭会实际通过每个节点访问远端目标并返回耗时。
   - **绿色 (20~80ms)**：延迟极低，非常适合日常刷网页、实时通话与网页秒开。
   - **黄色 (100~200ms)**：中等延迟，看 YouTube 4K 视频毫无压力。
   - **红色 / 超时 (Timeout)**：节点不可用，请勿选择。

2. **常见地区选择参考**
   - **香港 (HK)**：日常浏览首选，物理距离最近，国内访问响应极快。
   - **日本 (JP) / 新加坡 (SG)**：看亚洲流媒体与 AI 服务首选。
   - **美国 (US)**：版权库最全，访问美区专属服务必备。
