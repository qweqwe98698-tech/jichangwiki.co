# Shadowrocket 订阅更新失败与格式错误排查

<AnswerBox question="iPhone 小火箭刷新订阅报错 Update Failed 或列表空空如也怎么解决？">
请依序排查这 4 点：① <strong>老节点全挂时务必先关闭顶部主开关，直连刷新</strong>（或勾选设置中的「打开时更新」并切换 4G/5G 蜂窝网）；② 进 iOS 设置允许小火箭「从其他 App 粘贴」；③ <strong>复制链接放进 Safari 直接访问测试</strong>，排除机场域名失效或 404；④ 核对没有贴错成机场首页登录地址。
</AnswerBox>

---

## 一、四步精准排错流程（按高发率排序）

### 1. 排除“顶部开关开着老节点死锁” + 切换移动流量测试
如果机场原本配置的老节点已经全体阵亡，而你的小火箭顶部连接开关还处于绿色开启状态，此时下拉刷新的更新请求仍会被迫塞进死节点里，永远报超时失败。
- **操作**：先 **关掉顶部主开关**，断开公共 Wi-Fi 改用手机 4G/5G 流量，下拉首页尝试拉取一次。
- **反过来情况**：若确定手里还剩一条能联网的老节点，但机场官网和订阅域名已在本地被宽带阻断 ➔ 保持那条老节点连接状态，进小火箭 `设置 ➔ 订阅 ➔ 打开「通过代理更新」` 再下拉刷新。

### 2. 开启 iOS 剪贴板读取与本地网络权限
从 iOS 16 起苹果加强了隐私保护。如果提示粘贴无效：
- 打开 iPhone 系统 `设置 ➔ 向下滑动找到 Shadowrocket ➔ 从其他 App 粘贴` 改为 **「允许」**。
- 确保「无线数据」权限设为 **「无线局域网与蜂窝网络」**，避免软件根本没拿到联网许可。

### 3. 在 Safari 浏览器里“验真身”
把你导入小火箭的那一条订阅地址直接粘贴进 iPhone Safari 地址栏访问：
- 如果弹出询问下载文本或屏幕上展示一串很长的乱码字母 / YAML 结构，代表链接完全正常可用；回去仔细核对粘贴时是不是前后多了空格，或者按 [小火箭重新导入方法](/clients/shadowrocket/import-subscription) 删掉旧条目改扫码重添。
- 如果 Safari 直接报 `404` / `403` / 无法连接服务器，请查阅通用 [订阅链接打不开状态码解析](/subscription/url-not-working) 或回机场个人后台点击「重置订阅链接」。

### 4. 检查套餐有效期与节点过滤误操作
如果更新转圈完没有报错、只剩几行中文提示条（如剩余流量 0GB、已过期），代表套餐到期耗尽，详情见 [订阅过期判断指南](/subscription/expired)。另外检查小火箭主页列表最上方搜索框里有没有忘清空的残留关键字。

## 常见问题解答（FAQ）

### 小火箭更新订阅总是弹窗提示 Update Failed（请求超时）怎么修？

首先断开当前已经连着的旧节点（防止代理死锁），切回手机 4G/5G 流量下拉刷新；如果移动流量也失败但借助代理能在 Safari 打开链接，就打开小火箭 `设置 ➔ 订阅 ➔ 通过代理更新` 后再点刷新。

### 为什么在微信或浏览器复制好了链接，小火箭却识别为空或提示 Invalid Subscribe？

原因通常是：iOS 系统拒绝了软件读取剪贴板、复制时多粘进换行符或把网页 URL 当作订阅导入，或者经过微信传输时参数被转码，修复细节可对比 [导入报错排查](/subscription/import-failed)。

### 更新完订阅只剩 1~2 条奇怪的提示词节点没有正常国家怎么办？

提示字样通常写着套餐已到期、流量已用尽或官网变更，说明账户欠费或总流量用光了。请登录官网续费后再下拉刷新列表。
