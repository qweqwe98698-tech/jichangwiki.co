# Shadowrocket 导入订阅链接与二维码扫描

<AnswerBox question="小火箭怎么快速导入订阅？">
方法一：点击小火箭右上角「+」号，类型选择「Subscribe」，在「URL」一栏粘贴你的订阅链接，点击右上角「完成 (Save)」。方法二：点击左上角扫描图标直接扫描机场提供的订阅二维码。
</AnswerBox>

## 📷 方法二：二维码一键扫码

1. 在电脑或另一台设备上打开机场网站的订阅二维码。
2. 打开小火箭主界面，点击左上角的**扫描图标**。
3. 对准屏幕上的二维码扫码，小火箭会自动识别并一键完成全部节点的拉取与分组创建。
