# Shadowrocket 全局路由模式详解

<AnswerBox question="小火箭的「全局路由」应该选哪一个模式？">
日常使用**强烈推荐选择「配置 (Config)」模式**。在该模式下，国内网站自动直连（不耗流量、不卡顿），只有境外被阻断的网站才走代理节点。
</AnswerBox>

---

## 🧭 四大路由模式核心区别

在小火箭主界面中间，有一项「全局路由 (Global Routing)」，点击可切换以下四种工作模式：

| 路由模式 | 工作逻辑 | 流量消耗 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **配置 (Config) [推荐]** | 依照内置的分流规则判断：国内直连，国外走代理 | 仅境外流量扣除套餐配额 | **99% 日常使用场景首选** |
| **代理 (Proxy)** | **全局代理**：整机所有网络流量一律强制走所选节点 | 所有流量（包括微信/淘宝）均扣费 | 仅在规则失效或特定海外测试时临时使用 |
| **直连 (Direct)** | **全局直连**：所有流量都不经过节点，如同未开启代理 | 不消耗任何代理流量 | 临时暂停代理无需关闭 VPN 开关 |
| **场景 (Scene)** | 根据当前连接的 Wi-Fi 名称或蜂窝网络自动切换不同节点与路由 | 依据所设规则而定 | 在家与在公司需使用不同网络环境的高级用户 |
