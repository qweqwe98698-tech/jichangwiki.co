# iOS 下载与美区 Apple ID 安装教程

<AnswerBox question="在中国大陆 iPhone 上如何下载正版 Shadowrocket？">
在 App Store 中退出当前国区账号，登录已购买过小火箭的美区或外区 Apple ID；在 App Store 搜索「Shadowrocket」（开发者为 Guangming Li，图标为蓝底黄色纸飞机），完成下载即可。切勿在手机「设置」的 iCloud 中登录陌生账号！
</AnswerBox>

---

## ⚠️ 至关重要的安全红线

> [!CAUTION] 严防锁机风险
> 借用或使用外部提供的 Apple ID 时，**只能在「App Store」应用内登录**，**绝对严禁在 iPhone 的系统「设置」→「iCloud」中登录**！在系统设置中登录他人账号可能导致设备被远程锁定勒索！
