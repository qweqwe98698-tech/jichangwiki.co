# Stash 客户端知识中心

<AnswerBox question="什么是 Stash？它与 Clash 有什么关系？">
Stash 是专为 Apple 生态（iOS、macOS、Apple TV）打造的规则代理客户端。它原生支持 Clash YAML 配置文件与 Proxy Provider 订阅，被誉为“iOS 上的 Clash 最佳替代品”。
</AnswerBox>

---

## 🍏 核心功能亮点

1. **Clash 配置无缝导入**：可直接将任何标准 Clash 订阅链接粘贴导入，完整支持策略组嵌套与规则分流。
2. **全平台 Apple 设备支持**：支持 iPhone、iPad、Mac 甚至 Apple TV (tvOS)，并通过 iCloud 自动在所有设备间同步规则与配置。
3. **按需连接 (On Demand)**：支持检测特定 Wi-Fi 网络（如连接到家庭 Wi-Fi 时自动关闭代理，离开时自动开启）。
