# Clash Verge 节点全部超时 (Timeout) 排查

<AnswerBox question="Clash Verge 节点测速全部显示 Timeout 怎么办？">
优先检查三件事：① 电脑系统时间是否准确同步（与北京时间误差不能超过 60 秒）；② 订阅是否已到期或流量用尽；③ 在「订阅」页面右键点击配置卡片执行「刷新」，更新节点真实 IP。
</AnswerBox>

---

## 🛑 故障症状表现

- 在「代理 (Proxies)」页面点击一键测速，所有节点无一例外显示红色的 `Timeout`、`0ms` 或 `Error`。
- 浏览器无法打开任何境外网页，访问国内网页可能正常（若处于规则模式下）。

---

## ⚡ 30 秒快速检查清单

1. **第一步：校准本地电脑系统时间**
   - Windows：右键右下角任务栏时间 →「调整日期和时间」→ 点击「立即同步」。
   - 原因：代理协议中的 TLS 证书握手与 VMess/VLESS 认证对时间戳有严格限制，误差超过 60 秒将直接拒绝握手。
2. **第二步：手动刷新订阅配置**
   - 进入「订阅」页面，右键当前配置点击「刷新」。观察是否能成功拉取最新节点。
3. **第三步：核查套餐与流量状态**
   - 登录机场官网后台，确认账户未处于欠费停机状态，套餐流量未被消耗完毕。

## 🔧 常见深度根因与解决步骤

### 原因 1：内核防火墙与杀毒软件拦截
- **现象**：本地 Mihomo 核心进程 `clash-meta.exe` 被安全软件隔离。
- **解决**：在 Windows Defender 或第三方安全软件的“信任区/白名单”中，添加 Clash Verge 安装目录及内核进程。

### 原因 2：本地 DNS 解析死锁
- **现象**：Clash 内核在启动时无法解析节点服务器的域名（如 `hk01.example.com`）。
- **解决**：在 Clash Verge 设置中检查 DNS，确保 `default-nameserver` 配置了国内公开的公共 DNS（如 `223.5.5.5` 或 `119.29.29.29`）。

### 原因 3：服务模式与 TUN 驱动冲突
- **现象**：同时开启了其他代理软件（如 v2rayN、游戏加速器）导致虚拟网卡路由表冲突。
- **解决**：退出所有其他网络加速工具，在 Clash Verge 设置中关闭 TUN 模式再重新开启一次。
