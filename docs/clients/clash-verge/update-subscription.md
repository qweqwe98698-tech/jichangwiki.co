# Clash Verge 更新与维护订阅教程

<AnswerBox question="Clash Verge 怎么手动更新订阅并开启自动同步？">
在左侧「订阅 (Profiles)」页面，点击当前配置卡片右上角的「刷新」图标即可立即拉取最新节点；右键卡片选择「编辑信息」，将「更新间隔 (Update Interval)」设为 <strong>720</strong> 或 <strong>1440</strong> 分钟即可自动定时同步。
</AnswerBox>

> 如果你是首次导入订阅链接，请先查阅 [Clash Verge 订阅怎么导入图文教程](/clients/clash-verge/import-subscription)。

---

## 🔄 一、为什么要定期更新订阅？

许多用户遇到“昨天还能用，今天突然全部节点超时”，往往并不是机场跑路，而是服务商在后台迁移了入口域名、更换了落地端口或增加了新的高速节点。由于订阅配置文件保存在本地，客户端如果不向云端拉取最新 YAML 配置，本地记录的还是旧地址。

---

## ⚡ 二、手动刷新与定时自动更新配置步骤

### 1. 手动一键刷新（节点突然失效时首选）
1. 点击 Clash Verge Rev 左侧导航栏的 **「订阅 (Profiles)」**。
2. 找到正在使用（带有高亮边框）的配置文件卡片。
3. 点击卡片右上角的 **旋转刷新图标**（或右键卡片选择 **「刷新 (Update)」**）。
4. 右下角出现「配置更新成功」绿色提示，代表最新节点池已同步到本地。

### 2. 配置自动定时更新（一劳永逸）
1. 在目标配置卡片上点击 **鼠标右键** ➔ 选择 **「编辑信息 (Edit Info)」**。
2. 找到 **「更新间隔 (Update Interval)」** 输入框（单位：分钟）。
3. 填写推荐值：
   - 重度/日常主力用户：填写 `720`（每 12 小时自动更新一次）
   - 轻度或备用订阅：填写 `1440`（每 24 小时自动更新一次）
4. （可选）如果该订阅域名平时无法直接从国内宽带访问，可勾选 **「使用代理更新 (Use System Proxy)」** 或 **「允许不安全证书」** 视情况排查，但注意：如果当前没有可用节点却开启了「通过代理更新」，就会陷入无法拉取的死锁！
5. 点击保存生效。

## 🛑 三、更新订阅失败常见场景与修复对照

| 报错特征 | 根本原因 | 针对性修复办法 |
| :--- | :--- | :--- |
| **有网但点击刷新一直转圈或超时** | 本地宽带或 DNS 阻断了机场的订阅分发域名 | 临时关闭系统代理开关并在隐身浏览器打开订阅 URL 测试；或连上手机热点后再刷新 |
| **提示 `Invalid YAML` 或更新后节点全部消失** | 机场返回了网页维护提示页、账户已到期，或订阅链接误选了 Base64 格式 | 登录机场官网确认剩余流量与到期日；查看 [导入后没有节点排查](/subscription/no-nodes) |
| **提示 `403 Forbidden` / `404 Not Found`** | 你曾在机场官网后台点击了「重置订阅链接」，导致旧 Token 作废 | 删除 Clash Verge 里的旧配置卡片，从官网重新复制最新订阅 URL 按 [首次导入流程](/clients/clash-verge/import-subscription) 重新导入 |
| **开着代理更新成功，关掉代理就失败** | 属于订阅 API 域名被直连阻断的典型情况 | 右键配置卡片「编辑信息」勾选 **「通过代理更新」**，保证每次自动更新都走当前可用节点通道 |

## ❓ 五、常见问题 FAQ

### Q1：Clash Verge 订阅更新间隔设置多少分钟最合适？
推荐设置为 `720` 分钟（每 12 小时）或 `1440` 分钟（每 24 小时）。间隔太短会频繁向服务商订阅 API 发起请求，可能触发机场的防爬虫频率限制；间隔太长则难以及时同步新增节点或修复已更换域名的入口。

### Q2：点击刷新订阅时提示更新失败，需要删掉重装吗？
无需重装客户端。90% 的更新失败是由于直连网络无法访问订阅 API 域名或旧节点开启了“使用系统代理更新”导致死循环。可先在右键菜单确认 URL 是否有效，或切换网络环境后再点击刷新；若在官网重置过订阅 Token，则需重新复制新链接导入。
