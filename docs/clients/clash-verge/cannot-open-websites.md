# Clash Verge 连接成功但打不开网页

<AnswerBox question="Clash Verge 节点测速正常但就是打不开网页是什么原因？">
主要排查三点：① 主界面底部的「系统代理」开关是否真正开启；② 代理模式是否被误设为「Direct (直连)」或分流规则走错；③ 浏览器安装的代理扩展（如 SwitchyOmega）是否覆盖劫持了系统设置。
</AnswerBox>

---

## 🚦 逐步排查流程

1. **检查主开关状态**
   - 确认界面左下角或托盘图标的「系统代理」为开启状态（开关呈青色或亮色）。
2. **检查出站代理模式 (Mode)**
   - 在主界面顶部切换出站模式：
     - **Rule (规则模式)**：推荐模式。国内直连，国外走代理。
     - **Global (全局模式)**：若规则模式异常，临时切到全局模式测试能否打开 Google。如果全局模式能打开，说明是分流规则缺少了目标域名的匹配。
     - **Direct (直连模式)**：所有流量直连不走节点，请勿误选此项。
3. **排查浏览器代理扩展干扰**
   - 如果你的 Chrome 或 Edge 浏览器安装了 `Proxy SwitchyOmega`、`ZeroOmega` 等代理插件，插件的配置会直接覆盖 Windows 系统代理。
   - 解决方法：在插件中选择「系统代理」模式，或临时禁用该扩展。
4. **清理残留的系统代理设置**
   - 进入 Windows「设置」→「网络和 Internet」→「代理」，确认「使用代理服务器」指向的 IP 为 `127.0.0.1` 且端口与 Clash Verge 设置一致。
