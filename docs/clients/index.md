# 客户端知识中心

<AnswerBox question="主流操作系统中最推荐的客户端有哪些？">
Windows 推荐 **Clash Verge Rev** 或 **v2rayN**；macOS 推荐 **Clash Verge Rev** 或 **Surge**；iOS 推荐 **Shadowrocket**（小火箭）或 **Quantumult X**；Android 推荐 **v2rayNG** 或 **sing-box**。
</AnswerBox>

代理客户端是运行在本地终端上的路由转发与规则管理工具。一个优秀的客户端能够稳定接管系统流量、智能分流国内外数据、精准测试节点延迟，并具备强大的防 DNS 污染与 TUN 虚拟网卡能力。

## 📱 其他主流客户端快速索引

- **[v2rayNG (Android)](/clients/v2rayng/)**：安卓端最经典的代理工具，支持分应用代理。
- **[sing-box (跨平台)](/clients/sing-box/)**：新一代通用代理核心，性能强劲，内存占用极低。
- **[Hiddify (跨平台)](/clients/hiddify/)**：极简美观，多平台界面高度一致。
- **[Stash (iOS / macOS)](/clients/stash/)**：专为 Apple 生态打造的 Clash 兼容规则代理工具。
- **[Surge (macOS / iOS)](/clients/surge/)**：专业级网络调试与高级抓包工具。
- **[Quantumult X (iOS)](/clients/quantumult-x/)**：强大的 JavaScript 脚本重写与规则分流。
- **[NekoBox (Android / Windows)](/clients/nekobox/)**：基于 sing-box 核心的高性能代理工具。
- **[Loon (iOS)](/clients/loon/)**：轻量强大、支持丰富插件生态的 iOS 代理软件。
